# Specification: 运行资源与性能

**来源：** [add-local-personal-workbench](../archive/2026-09-11-add-local-personal-workbench/proposal.md)

**状态：** 2026-09-11 合并为正式规格；按用户要求提前归档，剩余验证见 [待验收清单](../../docs/verification/deferred-tests.md)。以下要求是后续验收依据，不表示全部场景已经通过。

**后续变更：** 2026-09-14 合并 [improve-editor-formatting](../archive/2026-09-14-improve-editor-formatting/proposal.md)，新增 PERF-05。本次预览着色的验收见 [验证记录](../archive/2026-09-14-improve-editor-formatting/verification.md)；PERF-03、PERF-04 等首版历史性能延期项目保持原状态。

## Requirements

### Requirement: PERF-01 按需加载与有界会话

应用必须（MUST）按目录加载树元数据、按打开动作读取正文，最多保持两个打开文档会话与两个编辑器。关闭或替换时释放正文、视图、语法树、图片与监听；不得静默淘汰 dirty 文档。临时读取缓冲必须在请求完成或取消后释放。

实施边界：最多展开 300 个目录；编辑器的撤销历史在累计 200 次正文变更或 4 Mi 个插入字符后重置，仅淘汰历史，保留当前正文和光标。剪贴板长文本分段渲染，离开模块或隐藏时释放所有分段。

#### Scenario: 打开大笔记库
- GIVEN 根目录含 1,000 篇笔记和 50 个目录。
- WHEN 用户选择该根目录并仅打开两篇笔记。
- THEN 不预读整个库的正文；目录展开才加载子项，只有打开文档保留会话；折叠和离开后的元数据缓存有界。

#### Scenario: 长时间编辑与频繁替换
- GIVEN 用户反复替换右侧文档并进行长时间编辑。
- WHEN 原文档已完成保存且被移出。
- THEN 其重型资源被释放；当前文档撤销记录、预览缓存和图片缓存有明确上限，达到上限可淘汰旧缓存但不可丢失当前正文。

### Requirement: PERF-02 隐藏后的后台活动

隐藏主窗口必须（MUST）暂停不必要的渲染与剪贴板监听。隐藏 60 秒且所有内容成功保存后，必须能释放主界面重型资源，仅保留再次唤起必需的系统入口、配置及最多两份文档恢复元数据。

#### Scenario: 保存成功后闲置卸载
- GIVEN 主窗口隐藏且不存在 dirty/冲突文档。
- WHEN 隐藏超过 60 秒。
- THEN 主界面资源释放，悬浮入口与快捷键仍有效；再次调出可从磁盘恢复模块、文档、模式和滚动状态。

#### Scenario: 未保存文档阻止卸载
- GIVEN 文档存在保存失败或冲突。
- WHEN 闲置卸载条件被检查。
- THEN 保留可恢复的编辑缓冲，不为达到内存目标丢弃内容；该异常状态单独记录内存，不混入正常常驻基准。

### Requirement: PERF-03 可复现的内存预算

应用必须（MUST）在 [design.md](../archive/2026-09-11-add-local-personal-workbench/design.md) 第 7 节指定的 Windows 发布构建环境与数据集下测量全部应用相关进程的私有工作集总和，并同时报告 Private Bytes、峰值、PID 清单和环境。以下是拟议验收预算，实施前先验证基线，未测量不得宣称达标。

| 状态 | 私有工作集总和 P95 预算 |
|---|---|
| 隐藏 60 秒后，悬浮开启 | ≤ 120 MiB |
| 单笔记，显示与编辑分别测量 | ≤ 200 MiB |
| 双笔记，均显示与均编辑分别测量 | ≤ 260 MiB |

#### Scenario: 完整进程集合采样
- GIVEN 发布构建正在基准环境运行，WebView2 有多个子进程。
- WHEN 每秒采样一次，稳定后记录 30 秒，并重复至少三轮。
- THEN 每个应用相关 PID 仅计一次且包含渲染/GPU等子进程，按表报告各状态 P95；超预算时优化或附数据修订规格后重新评审，不能只报宿主进程数值。

### Requirement: PERF-04 唤起延迟与重复操作保留内存

应用必须（MUST）分别测量保留界面和闲置卸载后的唤起，各 30 次，P95 目标分别为 300 ms 和 1,000 ms。必须完成三轮各 100 次相同操作循环，恢复相同状态并稳定 60 秒后，私有工作集和 Private Bytes 总和相对各轮预热基线的增量分别不超过 20 MiB。

#### Scenario: 唤起测量
- GIVEN 应用已运行，测试覆盖保留界面与闲置卸载两种状态。
- WHEN 从点击悬浮入口或按下快捷键开始计时。
- THEN 以目标文档可交互为终点报告 P95，不以空窗口刚出现代替正文可操作。

#### Scenario: 反复使用后资源回收
- GIVEN 应用完成预热，并记录基线内存与相同初始文档状态。
- WHEN 完成 100 次显示/隐藏、模块切换、模式切换、保存、目标替换和开关分屏循环，再回到相同状态并等待 60 秒。
- THEN 两项内存指标增量均满足上限；至少三轮的原始记录保留，若持续增长则定位并修复后复测。

### Requirement: PERF-05 有界预览着色

语言模块必须（MUST）按需从本地构建产物加载并共用。预览先显示安全纯文本，进入视口的代码块才加载/解析。单块超过 100,000 UTF-16 字符时不着色、不截断，并说明以纯文本显示。不得建立跨文档正文或语法树缓存；关闭/替换窗格后清理观察器与待处理工作，过期结果不得写入新页面。

#### Scenario: 大代码块与快速切换
- GIVEN 超长代码块或尚未完成语言加载的预览。
- WHEN 查看代码或切换/关闭窗格。
- THEN 正文完整可读，不为超长块增加 token DOM；旧任务不能修改新窗格，语言加载失败不阻断阅读。
