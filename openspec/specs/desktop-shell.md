# Specification: 桌面工作台入口

**来源：** [add-local-personal-workbench](../archive/2026-09-11-add-local-personal-workbench/proposal.md)

**状态：** 2026-09-11 合并为正式规格；按用户要求提前归档，剩余验证见 [待验收清单](../../docs/verification/deferred-tests.md)。以下要求是后续验收依据，不表示全部场景已经通过。

## Requirements

### Requirement: SHELL-01 全局快捷键与单实例

应用必须（MUST）支持可配置全局快捷键，默认 `Ctrl+Alt+Space`；隐藏或失焦时显示并聚焦已有主窗口，已聚焦时隐藏。重复启动必须激活已有实例。

#### Scenario: 其他应用在前台时唤起
- GIVEN 工作台已运行但隐藏，另一个应用拥有焦点。
- WHEN 用户按下已注册的快捷键。
- THEN 工作台显示并获得焦点，恢复上次模块与可恢复的文档状态，不新建第二个主窗口。

#### Scenario: 快捷键冲突
- GIVEN 用户设置的组合键无法注册。
- WHEN 应用尝试注册该组合键。
- THEN 设置界面显示冲突或失败；原有效绑定可继续使用，悬浮与托盘入口仍可用。

### Requirement: SHELL-02 悬浮入口

应用必须（MUST）提供可点击、拖动、关闭的悬浮入口；入口可置顶，但静置时不得主动抢占焦点。必须记住位置并在显示器配置变化后恢复到可见工作区。

#### Scenario: 点击与拖动
- GIVEN 主窗口隐藏，悬浮入口开启。
- WHEN 用户单击入口或将入口拖到新位置。
- THEN 单击显示并聚焦主窗口；拖动只改变入口位置，不误触打开。

#### Scenario: 关闭入口及显示器变化
- GIVEN 用户关闭悬浮入口，或保存入口位置的显示器已断开。
- WHEN 用户使用快捷键唤起，或重新开启悬浮入口。
- THEN 快捷键仍可唤起；重新开启的入口处于当前可见工作区。

### Requirement: SHELL-03 双模块导航

主窗口标题区域必须（MUST）持续提供「笔记管理」「剪贴板」入口。首次打开默认笔记管理，之后恢复上次模块；切换不得静默丢弃笔记修改。

#### Scenario: 模块切换并返回
- GIVEN 用户在笔记模块打开两个窗格。
- WHEN 用户切换到剪贴板，再返回笔记管理。
- THEN 文件树展开状态、两窗格文件、各自模式及滚动位置恢复；切换前的编辑内容已保存或仍被保留。

### Requirement: SHELL-04 隐藏、卸载和退出

关闭主窗口必须（MUST）隐藏应用，保留系统入口。明确退出必须结束后台运行并释放入口与快捷键。隐藏、模块切换、退出及闲置卸载必须遵守保存协议；保存失败时必须保留可见的错误及编辑缓冲，允许重试、另存或取消操作。

#### Scenario: 隐藏后恢复
- GIVEN 笔记已保存，用户关闭主窗口。
- WHEN 应用隐藏并在闲置 60 秒后释放主界面，用户再次点击入口。
- THEN 从本地文件恢复上次文档及轻量视图状态，不丢失已保存内容；系统入口在隐藏期间持续有效。

#### Scenario: 保存失败或明确退出
- GIVEN 当前笔记有未保存修改。
- WHEN 用户尝试隐藏或退出而保存失败。
- THEN 操作暂停，编辑缓冲仍可访问；用户处理保存问题后明确退出，所有应用进程及系统入口结束。
