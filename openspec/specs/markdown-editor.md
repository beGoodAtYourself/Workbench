## Requirements

### Requirement: EDIT-01 两种独立模式

每个笔记窗格必须（MUST）具有 Markdown 源码编辑模式及渲染显示模式。已有笔记默认显示，新建笔记默认编辑；模式切换在同一个窗格内进行，不增加文档窗格数量。

#### Scenario: 双窗格独立切换模式
- GIVEN 左 A、右 B 两个笔记窗格。
- WHEN 用户将 A 切换到编辑模式、B 保持显示模式。
- THEN A 可编辑、B 仍渲染显示，二者模式、光标和滚动位置独立；笔记窗格数量仍为两个。

### Requirement: EDIT-02 当前缓冲与保存状态

编辑与显示必须（MUST）使用同一文档会话的当前内容；必须展示未保存、保存中、已保存或保存失败状态。单纯切换模式不得丢失尚未写入磁盘的编辑。

#### Scenario: 保存前切换显示
- GIVEN 用户刚输入内容，自动保存尚未完成。
- WHEN 用户切换为显示模式，再切回编辑。
- THEN 显示最新缓冲内容，切回后内容仍在；保存状态仅由实际保存结果更新。

#### Scenario: 替换文档时保存失败
- GIVEN 活动窗格中的笔记存在未保存修改。
- WHEN 用户通过文件树打开另一个文件而原文件保存失败。
- THEN 保留原笔记及缓冲并提示处理；取消后不替换文档，另存或保存成功后才能继续。

### Requirement: EDIT-03 Markdown 展示范围

显示模式必须（MUST）支持标题、段落、列表、引用、代码块、表格、任务列表、标准链接与根目录内本地图片；正文中的脚本或原始 HTML 不得作为可执行内容运行。

显示模式必须保留段落内单次换行，空行继续分隔段落，不为此改写文件正文。编辑与显示模式必须共享语言注册表及语法配色，对显式标明受支持语言的代码块着色。支持 JavaScript、TypeScript（含 JSX、TSX）、Python、Java、C、C++、C#、Go、Rust、HTML、CSS、JSON、SQL、Shell、PowerShell、YAML，并识别常见语言缩写；未指定、不支持或加载失败时完整显示纯文本，不自动猜测语言。

#### Scenario: 常用语法与本地图片
- GIVEN 一篇包含上述语法和相对图片路径的笔记。
- WHEN 用户切换到显示模式。
- THEN 各语法按 Markdown 展示，本地图片相对于笔记所在目录解析并按需加载；任务列表在首版显示模式中为只读。

#### Scenario: 原始 HTML 或远程图片
- GIVEN 笔记包含脚本片段或远程图片 URL。
- WHEN 应用渲染正文。
- THEN 不执行脚本、不自动请求远程图片，展示安全文本或占位，仍可在编辑模式查看原始源码。

#### Scenario: TXT 换行与代码着色
- GIVEN 含单次换行、空行和指定语言代码块的笔记。
- WHEN 编辑或显示笔记。
- THEN 显示模式保留单次换行及段落间隔，代码关键字/字符串等可区分，代码缩进与文本完整保留。

### Requirement: EDIT-04 大文件保护

打开大于 2 MiB 的笔记前必须（MUST）提示文件大小，由用户选择继续加载或取消；不得无提示截断正文再保存。正常范围内的长文必须避免一次创建全部编辑行的 DOM。

实施上限为 64 MiB，超过后明确拒绝完整加载并建议外部编辑器，不创建截断版本。本地图片限制为每张 4 MiB、800 万像素，每个显示窗格最多同时保留两张图片；超限保留占位。

#### Scenario: 打开超大笔记
- GIVEN 目标 `.md` 文件大于 2 MiB。
- WHEN 用户尝试打开并选择取消。
- THEN 现有文档与布局保持不变；选择继续时完整加载或明确报告失败，不生成截断版本覆盖磁盘。

### Requirement: EDIT-05 可见选区

编辑和显示模式必须（MUST）清楚呈现选区。当前行背景不得遮住选区；编辑器聚焦与失焦使用可区分的选区颜色，失焦仍保留可辨认底色；显示模式提供原生文字选区样式。

#### Scenario: 选择当前行及跨行文字
- GIVEN 一个或两个编辑窗格，包含自动换行的长行。
- WHEN 用鼠标或键盘选择文字，随后操作工具栏或聚焦另一窗格。
- THEN 所选范围可见，当前行不遮挡底色，各窗格选区独立。

### Requirement: EDIT-06 格式工具栏

每个编辑窗格必须（MUST）在标题栏下方提供正文/H1–H3、加粗、斜体、有序/无序/任务列表、引用、行内代码、代码块、链接、撤销/重做工具栏。按钮具有中文提示及可访问名称，窄窗格可换行。点击工具栏保留编辑选区；行内格式使用选中文字或可替换占位文字；标题、列表和引用处理当前行或选中行，同格式可取消。每次修改为独立撤销事务，沿用自动保存。

代码块操作提供语言选择，默认“纯文本”，自动生成能容纳正文中已有反引号的有效围栏；在已有代码块内操作只修改语言，不嵌套代码块。

#### Scenario: 不熟悉 Markdown 的用户排版
- GIVEN 从 TXT 粘贴的多行文字。
- WHEN 选中标题或条目并点击格式按钮。
- THEN 生成对应 Markdown，焦点返回编辑区，正文保留；一次撤销还原此次操作，切换模式显示最新内容。

#### Scenario: 代码块及链接弹窗
- GIVEN 选中一段代码或链接文字。
- WHEN 选择代码语言或输入链接并确认。
- THEN 自动生成有效 Markdown；内部反引号不提前关闭围栏；已有代码块仅更新语言。取消弹窗不改正文并恢复选区。
