# Specification: 当前剪贴板显示

**来源：** [add-local-personal-workbench](../archive/2026-09-11-add-local-personal-workbench/proposal.md)

**状态：** 2026-09-11 合并为正式规格；按用户要求提前归档，剩余验证见 [待验收清单](../../docs/verification/deferred-tests.md)。以下要求是后续验收依据，不表示全部场景已经通过。

## Requirements

### Requirement: CLIP-01 当前文本展示

剪贴板模块必须（MUST）在进入或重新显示时读取当前系统剪贴板文本，视图可见期间根据系统变化更新，并提供手动刷新。显示是只读操作，不应改写系统剪贴板。

#### Scenario: 在其他应用复制文本后查看
- GIVEN 用户在其他应用复制了文本。
- WHEN 用户调出工作台并进入剪贴板，或让已打开的剪贴板模块恢复可见。
- THEN 显示当前文本；视图可见期间内容变化会更新，无需重启工作台。

### Requirement: CLIP-02 状态区分与读取上限

应用必须（MUST）区分空内容、非文本与读取失败。单次显示上限为 1 MiB UTF-8 文本，按完整字符截断并标注；读取边界必须限制大内容分配，不能为显示片段保留巨量完整副本。

实施约束：长文本以最多 4,096 个 UTF-16 码元一段显示，分段不能拆开代理项对，并提供上一段、下一段和段数。此分页不会减少可浏览的 1 MiB 快照范围，也不修改系统剪贴板。

#### Scenario: 非文本替换或剪贴板暂时不可读
- GIVEN 界面曾显示文本 A，当前剪贴板已为空、已换成图片或读取失败。
- WHEN 视图更新。
- THEN 显示对应状态，不能把 A 继续标为当前剪贴板文本；失败时允许手动重试。

#### Scenario: 超过显示上限
- GIVEN 当前文本 UTF-8 长度大于 1 MiB，包含中文或其他多字节字符。
- WHEN 用户查看剪贴板。
- THEN 仅显示不超过上限且字符完整的片段，并标明截断；系统剪贴板原内容保持不变。

### Requirement: CLIP-03 不持久化与离开释放

首版必须（MUST）只保留当前可见快照，不收集历史，不将内容写入磁盘或日志。离开剪贴板模块、隐藏主窗口或退出时必须取消变化订阅并释放快照。

#### Scenario: 离开后继续复制
- GIVEN 用户已离开剪贴板模块或隐藏主窗口。
- WHEN 系统剪贴板持续变化。
- THEN 应用不持续读取或累积内容；再次进入时只读取那一刻的当前内容，没有历史列表。
