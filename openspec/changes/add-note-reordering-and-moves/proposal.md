# Proposal: 单篇 Markdown 笔记排序与移动

**Change ID:** `add-note-reordering-and-moves`
**Created:** 2026-09-14
**Status:** Implementation Complete
**Completed:** 2026-09-14

## 问题与目标

上一变更只支持文件夹排序和跨目录移动，笔记拖动仍只能插入链接，右键菜单也缺少整理入口。用户要求单篇 Markdown 文件同样能够调整位置。

## 实施范围

- 笔记可拖至另一笔记行的上半／下半，在同级笔记之前／之后排序；跨父目录时移动并插入指定位置。
- 笔记拖到文件夹行时整行表示移入，拖到笔记库名称时移回根目录。跨目录继续确认源／目标路径和相对引用影响。
- 笔记右键菜单提供上移、下移、移动到及恢复同级默认排序。文件夹仍在笔记前，两组内部各自排序；恢复默认清除此父目录两组的自定义次序。
- 沿用排序偏好格式和命令，兼容已有仅文件夹顺序；新项目追加到所属组末尾，应用内重命名保持位置。
- 复用保存互斥、路径映射、错误恢复；真实文件移动不覆盖同名目标，不改变 Markdown 字节。保留笔记拖入编辑器插入链接。

不增加跨库移动、多选、自动改写正文引用或文件操作撤销。上一文件夹变更及其验收记录保留，本次为增量补充，参见 [任务](tasks.md) 与 [规格](specs/local-notes_delta.md)。

本变更依赖 `add-folder-reordering-and-moves` 的 FILE-07 至 FILE-09；后续归档应先合并文件夹变更，再合并本次 [LINK-01 增量](specs/note-links_delta.md)，将上一版“笔记拖回文件树不移动”的限制替换为新行为。
