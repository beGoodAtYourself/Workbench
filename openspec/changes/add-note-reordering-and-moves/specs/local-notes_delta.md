**Affects:** FILE-07 至 FILE-09 的单篇笔记补充

## ADDED

### Requirement: FILE-10 单篇笔记排序与移动

应用必须（MUST）允许单篇 `.md` 笔记在同父目录的笔记组内排序，以及移动到同一笔记库的其他目录或根目录。文件夹组始终先于笔记组，两组分别应用持久顺序；不允许以不同类型的项目作为前后插入锚点。支持拖动和键盘可操作的菜单。笔记行上半／下半显示前后插入线，文件夹整行作为笔记移入目标。

顺序与移动复用 FILE-07 至 FILE-09 的每库隔离、大小上限、保存冲突、安全边界、部分成功及会话保护。既有仅文件夹顺序必须保留；笔记新建／重命名／回收站与外部变化纳入相同整理规则。重置当前父目录时同时恢复两组名称顺序，子目录偏好不受影响。跨目录需确认，笔记文件名及字节保持完整，同名目标不得覆盖。

#### Scenario: 同级 Markdown 排序并恢复
- GIVEN 同一目录中有文件夹 X 和笔记 A.md、B.md、C.md，且已有文件夹顺序。
- WHEN 将 C.md 拖到 A.md 上半，或在菜单中上移。
- THEN 文件夹仍在所有笔记之前，笔记顺序为 C.md、A.md、B.md；刷新和重启保持顺序，原文件夹顺序不变，路径及正文不变。

#### Scenario: 移动打开的笔记
- GIVEN 双窗格中有已打开且含未保存修改的 A.md，目标目录为 X。
- WHEN 将 A.md 拖到 X 并确认。
- THEN 保存成功后移动到 X/A.md，保留模式、光标及编辑历史，后续保存只写新路径；保存失败或目标同名则保留原路径和缓冲。
- AND 同样可移回根目录或指定另一父目录笔记之前／之后的位置；取消确认不改动。

#### Scenario: 保留正文链接拖拽
- GIVEN 用户拖动一篇 Markdown 笔记。
- WHEN 在编辑模式的正文区域释放。
- THEN 插入指向该笔记的 Markdown 链接，不改变磁盘位置或排序；文件树落点才执行整理操作。
