## MODIFIED

### Requirement: LINK-01 拖拽生成可移植链接

用户将文件树中的单个 `.md` 文件拖入编辑模式窗格时，应用必须（MUST）在落点插入标准 `[名称](相对路径)` 链接。路径相对于当前笔记父目录，使用 `/` 分隔并正确编码特殊字符；此正文插入操作不得移动或复制目标文件。

文件夹在文件树或笔记库名称上的整理遵循 FILE-07 至 FILE-09，单篇笔记在这些区域的整理遵循 FILE-10。文件夹拖入正文不支持插入链接。必须（MUST）根据落点区分正文插入与树内整理，同一次拖动不得触发两个动作。

#### Scenario: 跨目录及特殊字符路径
- GIVEN 来源为 `项目/计划.md`，目标为 `资料/API 说明.md`，来源处于编辑模式。
- WHEN 用户将目标拖到正文指定位置。
- THEN 插入 `[API 说明](../%E8%B5%84%E6%96%99/API%20%E8%AF%B4%E6%98%8E.md)`，保存重开后仍指向同一文件；中文、空格、`#`、`%`、括号和方括号的变体均正确转义或编码。

#### Scenario: 不支持的正文拖拽
- GIVEN 用户将文件夹拖入正文，或将笔记拖入显示模式。
- WHEN 用户释放鼠标。
- THEN 不修改正文，不误触文件移动，界面说明该落点或项目不支持插入。

#### Scenario: 文件树与编辑器落点区分
- GIVEN 文件树同时支持文件夹、笔记整理及笔记拖动插入链接。
- WHEN 笔记拖到有效树内插入线、文件夹或笔记库名称，或拖入编辑模式正文。
- THEN 树内只执行笔记排序／移动，正文只插入链接；在无效区域释放不执行上述动作。
- AND 文件夹拖到笔记行不作为跨类型排序锚点；原有文件夹拖动及取消行为不变。
