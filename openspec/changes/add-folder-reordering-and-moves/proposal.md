# Proposal: 文件夹拖动排序与移动

**Change ID:** `add-folder-reordering-and-moves`
**Created:** 2026-09-14
**Status:** Implementation Complete
**Completed:** 2026-09-14

## 问题与目标

用户提出“文件夹列表可移动”，并确认同时需要：① 拖动文件夹调整列表上下顺序；② 把文件夹移入其他目录，改变层级。

改进前文件树只按名称排列，同级顺序不能自定义。拖拽仅用于把 Markdown 笔记插入编辑区作为链接；文件夹不能排序或跨目录移动。用户需要借助系统文件管理器整理层级，也无法把常用文件夹放在前面。

## 实施方案

在现有文件树中支持单个文件夹的拖动，通过插入线与目标高亮明确区分操作。根目录和嵌套目录均适用，文件夹继续排在笔记之前。

| 落点或入口 | 行为 |
| --- | --- |
| 同一父目录中，另一文件夹行的上沿／下沿 | 显示插入线，放到该文件夹之前／之后，只调整顺序 |
| 不同父目录中，另一文件夹行的上沿／下沿 | 移到该行所属父目录，并放到该文件夹之前／之后 |
| 另一文件夹行的中部 | 高亮目标文件夹，跨父目录时移入其中并排在其已有文件夹之后；已经属于该目录则无变化 |
| 左上方笔记库名称 | 跨父目录时移回笔记库根目录并排在已有顶层文件夹之后；已经位于根目录则无变化 |
| 文件夹右键菜单／更多文件操作 | 提供“上移”“下移”“移动到…”及“恢复同级默认排序” |

文件树空白处、笔记行、正文和工作台外部不是文件夹移动落点。拖到自身、后代或其他无效目标时明确显示不可放置；移动距离不足阈值仍执行原有点击。Esc、失焦或指针取消会终止拖动，释放落点提示及自动滚动任务。

同级排序完成即保存，无额外确认。跨父目录移动先展示源路径、目标路径和“相对链接及图片引用不会自动改写，可能需要修复”的说明，确认后执行；取消不改目录、顺序或打开会话。“移动到…”弹窗按层级浏览目标文件夹并提供根目录入口，按需加载，不扫描整个笔记库。

## 范围

### 本次包含

- 同级文件夹自定义排序，按笔记库持久保存，支持刷新、隐藏后恢复和退出重开。
- 单个文件夹跨父目录移动，包括移回根目录；整个目录内容一同移动，保留非 Markdown 文件。
- 插入线、移入目标高亮、中文拖动提示、长列表边缘自动滚动和可由键盘操作的菜单／目标弹窗。
- 新建、应用内重命名、回收站、外部目录变化后的排序整理；恢复同级默认排序。
- 未保存内容处理、双窗格会话路径更新、异常与过期请求处理。
- 原笔记拖入正文生成链接、格式工具栏、保存和分屏回归；Windows WebView2 验收与独立目录打包。

### 本次不包含

- 单篇笔记的排序或目录移动、多选批量移动、跨笔记库移动、复制／合并目录。
- 左侧面板位置或宽度调整、自动重命名冲突目标。
- 自动扫描或修复正文链接、图片引用；文件操作撤销历史。笔记编辑器的正文撤销仍维持原有行为。
- 首版已延期的完整性能和安装兼容性验收。

## 默认规则

1. 没有自定义顺序时沿用桌面版名称排序。演示实现使用相同规则；笔记的排序方式不变。
2. 已排序目录中的新增或外部新增文件夹追加在已排定文件夹之后，多个新增项按名称排序。移入目标文件夹或根目录时也追加；指定插入线时按该位置插入。
3. 已有自定义顺序的父目录中，应用内重命名保留相对位置；没有自定义顺序时按新名称排序。移动后迁移目录及后代的排序记录。外部重命名按“旧项消失、新项出现”处理，不猜测对应关系。
4. 只有成功列出的目录才清理已失效记录；未展开或读取失败不等同于不存在。刷新不预读笔记正文。
5. 同父目录的“移入父目录”视为无变化；拖动排序到原位置也不写入。首项／末项的“上移”／“下移”禁用。
6. 同名文件或文件夹冲突时拒绝移动，不覆盖、不合并。移动根目录、移入自身／后代、库外路径及不支持的链接目录均被阻止。
7. 排序偏好保存失败则还原此次排序并提示。若磁盘移动已成功而排序或恢复记录保存失败，保留新路径并明确提示哪项未保存，不报告整次移动失败或擅自反向移动。

## 影响与架构

| 组件 | 变化 |
| --- | --- |
| `src/main.ts`、`src/style.css` | 扩展现有 pointer 拖动，支持虚拟文件树落点、滚动、菜单及目标弹窗 |
| `src/types.ts`、`src/bridge.ts`、`src/demo.ts` | 增加文件夹移动、排序读取／更新的本地仓库接口；演示实现保持同样语义 |
| `src/model.ts` | 协调移动前保存与在途导航，保留文档对象并迁移路径，防止旧请求恢复旧路径 |
| `src-tauri/src/files.rs`、`commands.rs`、`app.rs` | 新增受根目录边界保护、不覆盖目标的目录移动命令，并注册桥接 |
| 本地偏好存储 | 在应用数据目录按规范化笔记库根路径隔离排序记录，不写入笔记目录，不挤占现有会话快照 |
| 文档与测试 | 新增排序／移动测试及实机记录，更新使用说明，保留既有验收边界 |

沿用 Tauri/Rust 与 TypeScript 架构，不增加数据库、网络服务或第三方拖拽依赖。正文仍为普通 UTF-8 Markdown。排序仅影响本应用列表；跨目录移动会改变磁盘路径。具体事务与持久化设计见 [design.md](design.md)。

## 风险与应对

| 风险 | 应对 |
| --- | --- |
| 排序与改变层级混淆 | 插入线与整行高亮区分；拖动提示写明目标动作；跨父目录确认实际新路径 |
| 移动后相对引用失效 | 移动确认说明链接和图片的影响，不自动改写正文；文档提供路径修复示例 |
| 保存或旧导航仍使用原路径 | 文件操作串行化，等待保存完成，使旧读取／导航／刷新结果失效后再提交路径映射 |
| 磁盘成功但偏好保存失败 | 磁盘结果为准，保留新会话路径，分别报告排序／恢复记录问题并可重试 |
| 长列表拖动命中旧行 | 保持虚拟渲染，按当前路径和布局判定落点，自动滚动后重新计算并在提交前复验 |
