## MODIFIED

### Requirement: LINK-01 拖拽生成可移植链接

用户将文件树中的单个 `.md` 文件拖入编辑模式窗格时，应用必须（MUST）在落点插入标准 `[名称](相对路径)` 链接。路径相对于当前笔记父目录，使用 `/` 分隔并正确编码特殊字符；不得移动或复制目标文件。

文件夹在文件树或笔记库名称上的排序／移动遵循 FILE-07 至 FILE-09，不使用正文插入逻辑。文件夹拖入正文仍不支持插入链接，笔记拖到文件树不触发文件移动；落点类型必须明确区分。

#### Scenario: 跨目录及特殊字符路径
- GIVEN 来源为 `项目/计划.md`，目标为 `资料/API 说明.md`，来源处于编辑模式。
- WHEN 用户将目标拖到正文指定位置。
- THEN 插入 `[API 说明](../%E8%B5%84%E6%96%99/API%20%E8%AF%B4%E6%98%8E.md)`，保存重开后仍指向同一文件；中文、空格、`#`、`%`、括号和方括号的变体均正确转义或编码。

#### Scenario: 不支持的正文拖拽
- GIVEN 用户将文件夹拖入正文，或将笔记拖入显示模式。
- WHEN 用户释放鼠标。
- THEN 不修改正文，不误触文件移动，界面显示该落点或项目不支持插入。

#### Scenario: 文件树与编辑器落点区分
- GIVEN 文件树同时支持文件夹排序／移动及笔记拖动插入链接。
- WHEN 文件夹拖到有效目录落点，或笔记拖入编辑模式窗格。
- THEN 前者仅按文件夹排序／移动规则处理，后者仅生成正文链接；相同拖动不会同时触发两个动作。
- AND 笔记拖回文件树或无效区域不会移动文件、生成正文链接或改变目录排序。
