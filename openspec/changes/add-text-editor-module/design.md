# Design: 独立文本编辑模块

**Change ID:** `add-text-editor-module`
**Status:** Implemented — Acceptance Pending

## 2. 模块和会话

导航枚举扩展为 `notes | text | clipboard`。启动默认仍为笔记管理；旧快照缺少文本记录视为空会话。笔记根目录、展开树和两个笔记窗格继续归笔记模块所有。

建议新增 `src/text-model.ts`、`src/text-editor.ts`、`src/text-search.worker.ts`、`src/text-workspace.ts`，以及 Rust `text_files`／`text_session` 模块；最终文件拆分可依实现调整，行为边界不得省略。

文本状态分为：

- 文档：稳定 `documentId`、授权引用（未命名时无）、显示名称／完整路径、正文版本、已写原文件版本、磁盘基准哈希、编码／BOM／EOL、只读／缺失／冲突状态。
- 标签：有序文档 ID，最多 12 个，关闭不触发替换其他 dirty 文档。
- 视图：最多两个不同文档 ID、活动视图、每文档光标／滚动／选区／语言／缩进设置。单文档不克隆进两个视图。
- 恢复：每文档最新持久化版本及所属清单代次，与原文件已保存版本分别记录。

非活动标签保留有界 `EditorState`，释放 `EditorView`／DOM／观察器。离开文本模块销毁可见视图；笔记模块离开时沿用现有视图销毁流程。全主窗口同时最多两个编辑器。

跨模块身份由宿主按规范路径及可取得的 Windows 文件身份去重，覆盖路径大小写与硬链接。已打开文件再次打开，切换至现有所属模块并聚焦；不合并两个独立 dirty 缓冲。另存目标若属于另一个活动会话则拒绝，不覆盖它。

## 3. 文件授权及保存

打开命令在 Rust 内调用原生文件对话框，选中的普通文件各自产生精确授权；读取失败不创建空白成功标签。多选按顺序逐项处理，报告失败项目，成功项保留；配额不足停止后续打开并说明，不自动关闭旧标签。

前端持有 `documentId`／不透明授权 ID，后续读取、检查变化及保存均通过此 ID。后端校验授权表、规范目标、文件身份和授权代次。不得以任意前端路径、扩展名、DOM 数据或快照路径授予文件访问。拒绝设备路径、目录和未授权目标；不扩大为所选文件父目录的通用授权。符号链接／junction 路径不能把既有授权静默转移到另一文件。

宿主单独持久化曾经通过对话框授权的记录；恢复清单只引用记录 ID。重启时复验记录完整性、目标规范身份和类型，身份变化要求重新选定；不可读／缺失时保留草稿但撤销原地写入能力。普通快照无法新增授权。

保存流程：

1. 捕获正文、编码／换行选择、编辑版本与已知原始字节哈希，单文档串行排队。
2. 严格编码并检查体积、写权限、授权与磁盘基准。未修改的普通保存不写文件；编码或换行选择变化属于 dirty。
3. 在目标同目录写临时文件并同步；提交前重新校验磁盘版本和身份，利用已有原子替换基础完成写入。失败不得破坏原文件。
4. 成功仅确认捕获版本，保存期间新输入继续 dirty。宿主同步更新本会话的文件身份，避免本应用原子替换被误判为外部换文件。
5. 恢复清单随成功结果更新，恢复更新失败显示「原文件已保存，恢复状态未更新」，不回滚磁盘或误报原文件写入失败。

另存由宿主对话框选定精确目标。新目标以不覆盖方式创建；已有目标先确认覆盖并捕获目标版本，提交时再次比较；竞态中新建／改变目标导致失败。取消不改变路径、授权、dirty 或原文件。另存成功迁移当前标签的路径／授权，原文件不改动。

只读文档可编辑缓冲、另存副本；原地保存失败保留内容。外部修改在重新聚焦／刷新时检查：文件身份未变、仅字节版本变化时，clean 会话更新，dirty 会话保留本地内容并暂停原地保存，提供另存、取消、明确确认后重载。外部原子替换导致身份改变时，无论是否 dirty 都保留当前缓冲，要求重新选择授权后读取，不能直接自动重载。外部删除不被保存自动重新创建，须另存或重新授权。

## 4. 编码与换行

按 BOM 检测 UTF-8 BOM、UTF-16 LE／BE；无 BOM 仅尝试严格 UTF-8。不自动猜测 GBK／ANSI，也不把任意无 BOM 字节按 UTF-16 解释。拒绝非法 UTF-8、UTF-16 奇数字节／孤立代理项、解码后 U+0000 和明显二进制签名，提示当前支持范围，不生成可覆盖原文件的有损缓冲。

新建默认 UTF-8 无 BOM、CRLF。现有文件保留其编码及一致的 LF／CRLF；没有换行的文件默认新增 CRLF。首期仅实现对正确解码的当前文本选择输出编码，不提供猜测旧编码重开。

混合 LF／CRLF 或 CR 文件打开时显示「混合」／「CR」，保留原类型元数据。无修改普通保存不写入；编辑后保存必须先让用户明确选择统一 LF 或 CRLF。取消保留当前缓冲且不写磁盘。该转换参与撤销，恢复记录保存原类型及当前选择；不因打开或切换标签自动统一。

编辑器内部按 LF 处理；UTF-16 代码单元偏移用于 CodeMirror 与检索，状态栏列号以 Unicode 码点计数，Tab 计一个字符，超界跳转定位到最近合法行列并提示。编码转换若发现不能无损表达的内容则阻止保存，保留缓冲。

## 5. 搜索与编辑

查找针对活动文档或打开面板时捕获的一个连续选区。提供普通文本、大小写、整词、正则、向前／向后、循环状态和命中计数。多选区时限定搜索仅使用主选区并明确提示。正则采用 JavaScript `u`／`m`，大小写选项控制 `i`，点号跨行是显式选项；不执行用户脚本。正则替换支持 `$1`／`$<name>`／`$$`，普通模式按字面替换。整词边界按 Unicode 字母／数字／下划线判断，正则模式关闭整词开关。

搜索及替换结果计算在可终止 Worker 内执行，单任务 1,500 ms 超时、最多 10,000 个匹配，超过时不执行全部替换；零宽匹配按 Unicode 码点前进。主线程只对可见范围绘制命中，不为所有匹配建立 DOM。任务绑定文档 ID、正文版本和搜索参数代次；正文变化／切标签／关闭面板使旧结果失效。

全部替换先生成完整变更集并校验正文上限，再以一次事务应用；超时、取消、超过匹配或正文配额均保持全文不变。限定选区随本次替换更新，选区外保持原文。撤销恢复全部替换前的内容及对应转换元数据。

常用命令：`Ctrl+N/O/S`、`Ctrl+Shift+S`、`Ctrl+W`、`Ctrl+Tab`／`Ctrl+Shift+Tab`、`Ctrl+F/H`、`F3`／`Shift+F3`、`Ctrl+G`、`Ctrl+Z/Y`、`Tab`／`Shift+Tab`、`Ctrl+D` 复制行、`Ctrl+/` 注释。提供菜单入口和中文可访问名称。快捷键只对所属模块／编辑区生效，输入框及弹窗优先，避免现有全局 `Ctrl+S` 重复保存。多光标采用 `Alt+单击`，矩形列模式后续设计。

## 6. 恢复与生命周期

文本模块手动写回原文件，但在停止编辑 1 秒后自动提交本机恢复。未命名文本也提交，含正文、输出格式、磁盘基准、授权记录引用、标签顺序和必要视图状态；不持久化撤销栈。状态栏显示「未保存到原文件／已暂存本机／暂存失败」，不以暂存成功清除 dirty。

恢复目录位于应用数据目录，正文与 `settings.json` 分离，不写日志。采用版本化清单、正文 blob 及同目录临时文件原子提交：先提交本代正文，再切换清单。切换清单前失败／超额保留上一有效代；新清单成功提交后新代即有效，再清理未引用旧代。清理失败只报告警告、继续计入配额并允许重试，不回滚新代或撤销其确认。恢复数据（含临时／待清理代）硬配额为 128 MiB；不得为挤出空间删除仍被有效清单引用的草稿。会话元数据上限 128 KiB，正文单代总上限 64 MiB。

模块切换、隐藏及正常退出先冻结生命周期提交范围，等待笔记保存和所有文本最新版本恢复成功，再提交联合元数据。后端按编辑代次核发确认凭据；新增编辑或恢复错误使凭据失效。宿主隐藏／60 秒卸载／退出复核凭据与当前代次，过期时拒绝销毁、恢复可见错误，保留内存缓冲。隐藏后禁止接受会改变正文的过期回调。

文本 dirty 但已完整暂存，可在 60 秒后卸载；笔记保存错误仍按旧规则阻止卸载。卸载后宿主不常驻全部文本正文；唤起先恢复清单和可见文档，后台标签正文激活时读取。自动登录启动不读取正文、不创建 WebView，沿用已有 `--autostart` 行为。

正常退出保留文本恢复记录，下次启动恢复。关闭单标签／关闭其他遇 dirty 时逐个提供「保存／不保存／取消」，不保存明确删除该标签的恢复数据。取消保留尚未处理标签，已明确关闭的标签不回滚。clean 标签直接关闭；删除恢复引用失败则不关闭并允许重试，防止已放弃内容在重启时重新出现。成功关闭后未引用 blob 可按配额规则清理。

恢复时比较磁盘身份及原始字节版本：一致时恢复草稿；身份不变但外部字节版本不同，dirty 标签显示冲突，clean 标签读取新磁盘内容；身份改变时保留草稿／已有缓冲并要求重新选择授权，文件缺失时保留草稿并提示另存。均不自动覆盖磁盘。损坏清单／正文隔离保留并提示，不能用空白恢复记录覆盖它。恢复失败不影响笔记和剪贴板使用。

## 7. 互操作和资源

笔记改名、移动、回收站命令在宿主检查受影响路径是否含文本会话；如有，返回相关标签并拒绝操作，前端引导切换及关闭。会话占用检查与磁盘操作共用串行区，避免检查后并发打开绕过。纯文件树排序不触碰磁盘路径，不受影响。

文本单文件读取上限 16 MiB，超过 2 MiB 用户确认；全部文本当前正文合计最多 16 Mi UTF-16 代码单元，输入、粘贴、恢复、替换和编码转换均在提交前复验。越界拒绝此次事务，显示原因，不裁剪。原文件保存产物同样不能超过单文件上限。每文档沿用现有 200 次正文变更或累计 4 Mi 插入代码单元的撤销历史重置边界，重置不删除当前正文。

语言模块和 Worker 离线随包加载；关闭、切换和卸载停止 Worker／定时器，丢弃过期结果，释放视图与不再引用的正文。新资源状态与原有笔记性能场景分别报告，预算和测量方法见 [资源增量](specs/runtime-resources_delta.md)。

## 8. 验证与交付

模型测试覆盖标签／视图、保存并发、代次、恢复提交、关闭取消、跨模块去重及上限；Worker 测试覆盖 Unicode、正则错误／超时、零宽和原子替换。Rust 测试使用隔离临时文件，核对支持编码和 BOM 字节、EOL、路径授权、竞态、只读／删除、恢复损坏／配额／断点。

Playwright 的 demo 覆盖交互、快捷键、错误、旧配置及现有功能回归。Windows WebView2 发布版另验收原生打开／另存、覆盖取消、中文路径、真实文件冲突、草稿隐藏 60 秒卸载／恢复及无 WebView 时退出。使用 `.qa/` 隔离目录和独立应用标识，保留正式自启动项及个人文件。

发布输出使用 `src-tauri/target/text-editor/` 独立目录，保留现有产物；记录检查命令、原生验收证据、性能原始数据与可执行文件／安装包哈希。未完成的既有自启动登录验收和首版性能项目不因本变更自动标记通过。

## 9. 实施补记（2026-10-16）

共享编辑基础、文本模型／工作区、Worker、Rust 文件授权与恢复模块已按上述边界落地，未增加依赖。初始化清单及可见正文尚未恢复完成时锁定外壳，完成后恢复活动编辑器焦点，避免提前导航覆盖恢复状态。

资源诊断发现大量重复正文 IPC 与编辑视图分配会提高渲染器保留内存。实施后仅对宿主已确认且文档对象、版本、长度均匹配的正文省略重复恢复传输；新增、改动、重新绑定及未确认正文仍完整提交。条件读取只在严格授权、身份、完整读取与解码校验后，对相同版本省略返回正文；旧的不带已知版本读取协议保持兼容。它们不放宽宿主的持久化或文件校验。

编辑器销毁后仅保留有界历史、输出格式与选区等纯状态，移除视图回调、插件和语言状态；关闭动画帧。相邻标签切换及排序复用仍可见的编辑器和标签节点，保留选区与焦点。语言完成后按实际注释／折叠能力刷新菜单，加载中、不支持及失败回退的命令保持禁用，过期加载不更新新文档。

第二次资源修正将焦点及文件刷新限定为活动模块正文，目标模块重新激活时先复核外部变化，树元数据仍单独刷新。编辑器只缓存当前版本的平铺字符串并与模型共享，不在纯布局、重挂或查找时重复拼接全文；历史状态仍有原上限。相同文档、编辑版本和参数的在途查找共享同一 Promise／Worker，编辑、改参数、取消、关闭或销毁仍使旧结果失效并终止任务。按 Enter 立即搜索前取消输入防抖计时，纯文本初始挂载不再空重配语言插件。

后续将状态栏控件的复用键限定为实际编辑设置，不因文档 ID 改变而重建相同的语言／编码／换行选项。事件处理在交互时读取当前文档，避免复用后仍修改旧标签；未变化的计数、保存状态、行列及窗格文字也保留原节点。性能脚本增加只记录元数据的样本完整性检查，意外输入使场景无效并保留失败尝试，不改变预算和采样数量。

最终自动化与原生证据、性能验收及保留限制统一记录于 [verification.md](verification.md)。当前状态不表示所有系统入口或历史验收完成，也未执行规格归档。

## 10. 短暂隐藏的视图暂停（2026-10-23）

10月22日完整复测仍有两轮增长超出20 MiB。后续无界面诊断确认：两个100 KiB文档短暂隐藏／恢复100次会重建200个编辑器；这证明存在重复分配路径，不等于已经定位全部原生保留内存。

短暂隐藏改为保留当前最多两个视图容器、正文、选区与有界撤销状态，重配为只读、不可编辑的最小状态；移除视图插件、语言解析、装饰和回调，终止搜索Worker、取消滚动动画帧，废弃过期语言加载。文档、格式和选区事务在暂停期间被拒绝；已排队的历史重置也必须保持暂停状态。恢复前由现有模块逻辑复核磁盘版本／身份，变化的文档销毁旧视图后重建；未变化的恢复原视图与可编辑状态、语言、滚动和焦点。

切换模块、退出和显式销毁仍释放全部文本视图；60秒卸载仍由宿主核验最新已持久化代次后销毁整个WebView，未改变后端协议。暂存失败则恢复同一视图、缓冲和焦点，不允许靠隐藏丢弃输入。PERF-02允许卸载前保留暂停的当前视图，未增加后台标签编辑器。
