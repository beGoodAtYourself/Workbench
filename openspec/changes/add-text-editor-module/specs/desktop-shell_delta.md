# Delta: 三模块导航与文本恢复生命周期

**Change ID:** `add-text-editor-module`
**Affects:** SHELL-03、SHELL-04、SHELL-05；SHELL-05 基于未归档 `add-launch-at-startup`，仅扩展恢复会话数量

## ADDED

（无。）

## MODIFIED

### Requirement: SHELL-03 三模块导航

主窗口标题区域必须（MUST）持续提供「笔记管理」「文本编辑」「剪贴板」。首次打开默认笔记管理，之后恢复上次模块；旧双模块配置兼容，缺少文本记录时使用空文本会话。各模块状态独立，切换前笔记按原保存协议完成保存，文本按 TEXT-08 提交最新本机恢复，失败保留原模块和缓冲。

切换笔记库只重置笔记路径／展开树／窗格，不清空文本标签、正文和恢复记录。离开模块释放可见编辑器、预览／剪贴板和搜索任务，返回后恢复该模块的视图状态。

#### Scenario: 三模块切换

- GIVEN 笔记双窗格及未保存文本标签均存在。
- WHEN 切换到剪贴板，再依次返回两个编辑模块。
- THEN 各自正文、布局和视图状态恢复；笔记遵守自动保存，文本仅本机暂存，不自动写原文件。

#### Scenario: 旧配置与切换笔记库

- GIVEN 旧配置没有文本模块字段，或文本标签已有未保存草稿。
- WHEN 升级启动或选择另一笔记库。
- THEN 旧笔记／剪贴板配置正常恢复，文本模块可使用；换库保留文本标签与草稿，取消换库保留原工作区。

### Requirement: SHELL-04 隐藏、卸载和退出

关闭主窗口必须（MUST）隐藏应用并保留系统入口，明确退出结束后台运行并释放入口和快捷键。明确退出不清除自启动注册，下次登录仍可启动，不在当前登录会话自动重启。隐藏、切换模块、退出及闲置卸载必须遵守笔记保存和文本本机恢复协议；失败不得丢弃缓冲或静默继续。

隐藏前笔记保存完成、文本最新版本及会话清单成功持久化后，宿主才确认本次生命周期代次；隐藏 60 秒后复核确认仍有效方可卸载主 WebView。文本仍 dirty 但已完整暂存时可卸载，未暂存／确认过期／提交失败时不得销毁，必须保留或恢复可见的错误与缓冲。不得只凭前端发起过保存请求销毁界面。

正常退出保留文本恢复记录，下次唤起／启动按 TEXT-08 恢复。无主 WebView 时托盘退出可直接结束宿主，已提交恢复记录保持有效。自动登录启动仍只初始化入口，不预读正文；用户首次唤起才按需恢复最多两个笔记会话和最多 12 个文本标签，正文按资源规格延迟读取。

#### Scenario: 未保存文本隐藏卸载

- GIVEN 文本标签存在未写原文件的草稿，笔记已保存。
- WHEN 最新草稿暂存成功后隐藏满 60 秒并再次唤起。
- THEN 主界面可卸载，草稿、dirty 状态和视图恢复，系统入口始终有效，原文件不被隐藏操作改写。

#### Scenario: 过期确认与暂存失败

- GIVEN 生命周期确认后又发生编辑，或本机恢复提交失败。
- WHEN 请求隐藏、卸载或退出。
- THEN 宿主拒绝使用旧确认销毁界面，保留最新编辑及可重试错误，不以缓存元数据代替完整正文。

#### Scenario: 正常退出和后台启动

- GIVEN 最新文本恢复已提交。
- WHEN 正常退出后重开，或用户登录触发后台启动后首次唤起。
- THEN 正常重开恢复会话；后台启动阶段不创建 WebView、不读取正文、不抢焦点，首次唤起按需恢复。

### Requirement: SHELL-05 当前用户开机自启动

Windows 桌面发布版必须（MUST）在设置中提供「开机自启动」，表示当前副本的当前用户登录启动项是否已注册。没有已有注册项的新装或旧版升级默认关闭；仅用户变更开关并成功保存后启用或关闭。取消设置不得（MUST NOT）写入自启动项。

每次打开设置必须查询系统注册状态并展示目标位置，区分未注册、当前副本、另一副本及读取失败。读取失败显示未知及重试，不假定关闭或报告成功，其他可用设置仍可保存。另一副本占用时提示主动开启可切换到当前程序；关闭只删除匹配当前副本的项。外部删除后不得根据缓存补回，保存其他设置不得重写注册；检测到外部变更必须刷新状态并提示重试。

开关不代表 Windows 允许运行，必须说明系统禁用可能阻止启动，不覆盖系统禁用或策略。自动启动必须携带 `--autostart` 来源标记，在用户登录后仅初始化配置、托盘、全局快捷键及按偏好显示的悬浮入口；不得主动显示主窗口、抢占焦点、读取笔记／文本正文或启用剪贴板监听。主 WebView 在用户唤起时才创建，恢复既有模块、最多两个笔记会话和最多 12 个文本标签；只按可见／激活动作读取文本正文。可恢复的配置解析错误及快捷键注册失败保留至首次打开界面提示，不自动弹窗抢焦点。

#### Scenario: 开启、关闭及取消

- GIVEN 当前副本未注册自启动，拾页正常运行。
- WHEN 用户开启／关闭并成功保存，或取消修改。
- THEN 成功操作注册或移除当前副本的命令，不要求管理员权限；取消不改变注册，其他程序的项不受影响。

#### Scenario: 后台登录与首次唤起

- GIVEN 自启动开启且未被系统禁止，最近模块为文本编辑并有 12 个标签。
- WHEN 用户登录 Windows，随后首次唤起拾页。
- THEN 后台阶段保持单实例、入口就绪、不创建 WebView／读正文／抢焦点；唤起恢复三模块状态及有界标签，按需读取可见文本，未保存草稿按 TEXT-08 恢复。

#### Scenario: 外部删除、禁用和另一副本

- GIVEN 注册可能被外部删除、被系统禁用或指向另一副本。
- WHEN 用户查看设置或保存其他设置。
- THEN 显示实际注册目标，删除后显示关闭，不绕过系统禁用；不自动补回／改写注册，关闭本副本不删除另一副本的项，主动开启可切换到当前程序。

#### Scenario: 操作失败与状态不可用

- GIVEN 注册读取／写入／读回、本地设置或恢复操作失败，或处于浏览器预览。
- WHEN 查询或保存自启动设置。
- THEN 不报告虚假成功，保留错误及重试，尝试恢复原注册／快捷键／本地设置，部分恢复失败后重读实际状态；读取失败显示未知，浏览器禁用该开关，其他可用设置仍能操作。
