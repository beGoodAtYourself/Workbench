# Delta: 有界多标签与恢复资源

**Change ID:** `add-text-editor-module`
**Affects:** PERF-01、PERF-02；新增 PERF-06；PERF-03／04／05 原场景与历史验收状态保留

## ADDED

### Requirement: PERF-06 文本模块资源验收

必须（MUST）在原 PERF-03 指定的 Windows 发布环境、完整应用进程集合及指标方法下，单独测量新增文本场景，不以宿主进程内存或开发浏览器代替。拟议 P95 私有工作集总和预算如下，实施前记录基线，未测量不得宣称达标。

| 文本场景 | 数据集 | P95 预算 |
|---|---|---|
| 单标签单视图 | 1 个 100 KiB UTF-8 文本，笔记会话为空 | ≤ 200 MiB |
| 双标签双视图 | 2 个各 100 KiB 的 JSON／TypeScript 文件，笔记会话为空 | ≤ 260 MiB |
| 满标签切换稳定后 | 12 个各 100 KiB 文本／源码、另有 2 个各 100 KiB 的已保存笔记会话，文本双视图 | ≤ 320 MiB |
| 隐藏 60 秒卸载 | 满标签状态完成本机恢复，悬浮入口开启 | ≤ 120 MiB |

每场景预热稳定后每秒采样 30 秒、至少三轮，同时报告 Private Bytes、峰值、PID 与环境。最大允许正文数据另做压力记录：12 个文档合计 16 Mi UTF-16 代码单元，其中至少一个接近单文件 16 MiB，完整打开／拒绝边界与编辑、保存、卸载可用，不把小文件预算宣称为最大体积实测预算。

保留界面／卸载后唤起各测 30 次，以活动文档可编辑为终点，P95 目标分别 300 ms／1,000 ms。三轮各 100 次标签替换、搜索取消、开关双视图和隐藏／恢复循环，回到相同初始状态稳定 60 秒后，私有工作集及 Private Bytes 相对预热基线各增量不超过 20 MiB。超预算需优化或带数据修订提案后评审，不静默放宽。

#### Scenario: 多标签与卸载测量

- GIVEN 隔离 Windows 发布版及上述固定数据集。
- WHEN 完成内存、唤起和三轮重复操作采样。
- THEN 原始数据及全部 PID 可复核，分别报告各场景与预算，不将笔记历史延期验收标为本次已通过。

## MODIFIED

### Requirement: PERF-01 按需加载与有界会话

应用必须（MUST）按目录加载笔记树元数据、按打开动作读取正文；笔记模块仍最多两个文档会话，文本模块最多 12 个标签／文档会话。主 WebView 只挂载当前模块的最多两个编辑器；其他标签／模块不得常驻额外编辑视图。不得静默淘汰 dirty 或未成功暂存文档。

笔记保留 300 个展开目录及原读取／预览边界。文本单文件原始字节上限 16 MiB、2 MiB 确认、所有文本当前正文合计上限 16 Mi UTF-16 代码单元。每文档撤销历史在累计 200 次正文变更或 4 Mi 插入代码单元后重置，仅淘汰历史，保留当前正文与光标。

文本会话元数据最多 128 KiB，恢复正文单代合计最多 64 MiB，包含临时／旧代的整个恢复数据配额为 128 MiB；达到上限明确失败，不删除仍有效草稿。恢复后仅按激活读取后台标签正文，不能为显示标签预读全部内容。关闭／替换／卸载清理正文、语法树、搜索 Worker、观察器及监听，临时缓冲请求完成或取消后释放。

#### Scenario: 满标签与模块切换

- GIVEN 两个笔记会话和 12 个文本标签。
- WHEN 在模块和标签间切换。
- THEN 每次最多两个可见编辑器，非活动标签没有编辑器 DOM，正文和恢复配额有界；超限操作不裁剪内容或暗中关闭旧标签。

#### Scenario: 长时间编辑与关闭回收

- GIVEN 反复编辑、搜索和替换标签。
- WHEN 关闭文档或卸载主界面。
- THEN 视图、Worker、正文引用和过期任务释放，语言模块可共用但不得建立跨文档正文缓存。

### Requirement: PERF-02 隐藏后的后台活动

隐藏主窗口必须（MUST）暂停不必要的渲染、检索和剪贴板监听。隐藏 60 秒且笔记已保存、文本最新正文及会话恢复已持久化、宿主确认代次有效后，必须可释放主界面重型资源，仅保留系统入口、配置、最多两份笔记及 12 份文本轻量恢复元数据，不在宿主保留所有文本正文。

笔记保存失败，或文本未暂存／恢复失败／确认过期时，禁止销毁内存缓冲，错误保持可访问。异常状态单独记录，不混入正常常驻基准。恢复内容从本机磁盘按需读取，后台启动不预读。

#### Scenario: dirty 已暂存与未暂存

- GIVEN 文本有未保存到原文件的编辑。
- WHEN 隐藏达到 60 秒。
- THEN 最新版本完整暂存且宿主确认有效时允许卸载；否则保留缓冲及错误，不能为达到预算丢弃输入。
