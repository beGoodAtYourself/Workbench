# Delta: 通用文本与代码编辑

**Change ID:** `add-text-editor-module`
**Affects:** 新增能力 `text-editor`，TEXT-01～TEXT-09

## ADDED

### Requirement: TEXT-01 独立文本工作区与文件命令

应用必须（MUST）提供无需选择笔记库即可使用的「文本编辑」模块，支持新建未命名文本、原生多选打开、保存、另存为、全部保存、关闭及关闭其他标签。保留用户文件扩展名，不自动补 `.md`。`.txt`、`.log`、配置、源码及 `.md` 等均按严格文本检测读取，未知扩展名可按纯文本使用；不得执行其中代码或 HTML。

#### Scenario: 无笔记库新建并保存

- GIVEN 用户没有配置笔记库。
- WHEN 进入文本编辑，输入中文并另存为 `配置示例.txt`。
- THEN 文件在用户选定位置按默认 UTF-8 无 BOM／CRLF 保存，标签显示实际文件名和路径，不创建笔记库。

#### Scenario: 多选包含失败项目

- GIVEN 用户通过对话框选择三个文件，其中一个不可读取。
- WHEN 按选择顺序打开。
- THEN 成功项保留独立标签，失败项说明原因；取消对话框不改变当前内容。达到配额后停止后续打开并说明，不静默淘汰已有标签。

### Requirement: TEXT-02 多标签与双视图

文本模块必须（MUST）支持最多 12 个标签、一个或两个并排视图及每文档独立的光标／选区／滚动／语言／缩进状态。切换、排序或将标签移到另一视图不修改正文，不丢失可用撤销历史。两个视图显示不同文档；重复打开同一规范文件必须激活现有所属模块会话，不创建第二份可写缓冲。另存目标已被另一会话占用时拒绝覆盖；恢复和多选打开遵循同一身份注册规则。

#### Scenario: 切换标签和双视图

- GIVEN A、B、C 已打开，A 有未保存编辑及撤销历史。
- WHEN 在标签间切换，将 B 移到另一视图，再回到 A。
- THEN A 的内容、光标和撤销历史保留，两个视图可独立切换；关闭第二视图只合并标签，不关闭文档。

#### Scenario: 重复与标签上限

- GIVEN 已有 12 个标签，且一个文件已在笔记模块打开。
- WHEN 打开重复文件或尝试打开第 13 个新文件。
- THEN 重复项激活现有模块／会话；新增项被明确拒绝，已有标签和内容不变。

### Requirement: TEXT-03 显式保存与关闭保护

文本原文件必须（MUST）仅由用户保存命令写回；本机恢复不等同原文件已保存。提供未保存、保存中、已保存、只读、失败及暂存状态。保存必须按文档串行处理原始字节版本／身份核验及同目录临时文件替换，失败不清除 dirty。另存取消保持原路径和缓冲，覆盖已有目标需确认且提交前复验目标版本；无目标时禁止竞态覆盖。

保存期间的新输入不得被旧保存结果确认。全部保存逐文档执行，取消或失败时停止后续项目，保留此前成功结果及剩余 dirty。关闭 dirty 标签提供「保存／不保存／取消」；关闭其他逐项处理，取消保留未处理标签。

#### Scenario: 保存期间继续输入

- GIVEN A 版本 1 正在保存。
- WHEN 用户输入版本 2，而版本 1 随后成功。
- THEN 仅版本 1 被确认，版本 2 仍未保存并保留，下一次保存写入版本 2。

#### Scenario: 另存及关闭取消

- GIVEN 未命名或 dirty 文本。
- WHEN 另存取消、目标在提交前被外部改写、或关闭时选择取消。
- THEN 不改原文件、不关闭标签、不改变 dirty 或丢弃缓冲，报告冲突或保留当前操作状态。

#### Scenario: 原文件已保存但恢复更新失败

- GIVEN 原文件写入成功。
- WHEN 后续恢复清单更新失败。
- THEN 明确显示「原文件已保存，恢复状态未更新」，可重试恢复，不把磁盘成功回滚或再次误标原文件 dirty。

### Requirement: TEXT-04 文本／代码编辑与语言

编辑区必须（MUST）提供行号、清楚可见选区、撤销／重做、复制当前行、缩进／反缩进、Tab／空格及 2／4／8 宽度、自动换行开关、多光标和跳转行列。按扩展名选择语言，可手动改为任一受支持语言或纯文本；语言切换不修改文件正文。共用现有 18 个代码语言入口及 Markdown／XML，支持可用模式的折叠、括号匹配和注释；无相应语法能力时禁用相应命令并说明。

所有模块文件和语言资源必须（MUST）离线可用，未识别语言或加载失败完整回退纯文本。状态栏显示活动文档行列、语言、编码、换行及保存状态。跳转行列从 1 起，列以 Unicode 码点计数、Tab 计一个字符；超界定位最近合法位置并提示。

#### Scenario: 语言切换与加载失败

- GIVEN 一个 `.json` 文件及一个未知扩展名文件。
- WHEN 打开后手动切换语言，或语言模块加载失败。
- THEN JSON 使用对应着色，未知／失败按纯文本显示，正文和 dirty 不因显示设置变化而改变。

#### Scenario: 中文和多光标编辑

- GIVEN 含中文、emoji、Tab 与长行的文档。
- WHEN 跳转行列、使用 Alt+单击建立多个光标并编辑，或切换换行显示。
- THEN 坐标与状态栏一致，多光标修改可撤销，显示设置不改磁盘换行或正文。

### Requirement: TEXT-05 当前文档查找替换

必须（MUST）支持活动文档或捕获的连续主选区内的普通／正则查找、大小写、普通模式 Unicode 整词、前后／循环查找、命中计数、单次替换和全部替换。正则按 JavaScript Unicode／多行语义，点号跨行可选；替换支持捕获组，界面说明语法，不承诺 Notepad++ 引擎兼容。

计算必须在可终止 Worker 内执行；单次 1,500 ms 超时，最多 10,000 个匹配。超时、非法表达式、超过匹配上限、取消、正文超额或文档版本过期时不得应用全部替换。零宽匹配必须安全前进，不无限循环。全部替换为一次可撤销事务，限定选区以外的文本不变。

#### Scenario: 选区内批量替换

- GIVEN 一段选区内外均有同样文字。
- WHEN 选择限定选区并执行全部替换，再撤销一次。
- THEN 仅选区内修改，报告数量；一次撤销恢复全部修改。

#### Scenario: 无效、零宽和过期搜索

- GIVEN 非法／高耗时正则、Unicode 零宽匹配或运行中的搜索。
- WHEN 搜索报错、超时、用户继续输入或切换标签。
- THEN 主界面仍可操作，旧结果不能写入新文档，正文未发生部分替换；零宽搜索正常终止。

### Requirement: TEXT-06 编码与换行

必须（MUST）严格支持 UTF-8 无 BOM、UTF-8 BOM、带 BOM 的 UTF-16 LE／BE，并保留现有编码／BOM及一致 LF／CRLF。无 BOM 只尝试 UTF-8；非法序列、UTF-16 奇数字节／孤立代理项、解码后 U+0000 或明确二进制不得作为可保存文本打开。不支持的编码提示原因，禁止替换字符解码后覆盖原文件。

编码／换行的输出转换须显式操作，标记 dirty 且可撤销；无正文／格式变化的普通保存不重写文件。混合 LF／CRLF 或 CR 文件明确显示原类型，编辑后保存前必须确认统一为 LF 或 CRLF，取消保留缓冲且不写磁盘。转换后不能无损编码或超限时阻止保存。

#### Scenario: 编码与 BOM 往返

- GIVEN 支持编码的中文／emoji 文件及 BOM／LF／CRLF 夹具。
- WHEN 打开后普通保存，或显式选择另一编码并保存。
- THEN 无修改不重写；有修改按选定编码及换行完整写入，BOM 正确，未选择转换时原格式保留。

#### Scenario: 混合换行与坏编码

- GIVEN 混合换行文件或非法编码文件。
- WHEN 用户打开、编辑并尝试保存。
- THEN 混合文件要求先确认统一，取消不改磁盘；坏编码拒绝打开且保留原字节，不生成截断／替换内容。

### Requirement: TEXT-07 外部变化与授权

库外文件必须（MUST）仅由宿主原生打开／另存对话框精确授权；后续 IPC 使用不透明 ID，前端任意路径或普通快照不得获得读取／写入权限。保存和恢复复核目标身份，路径别名或链接更换不得把授权转移至另一个文件。

重新获得焦点或刷新必须检查磁盘变化：身份不变且仅字节版本改变时，无本地修改则重载，有修改则保留双方并显示冲突，提供另存、取消或明确确认后丢弃本地并重载。身份变化（包括外部编辑器原子替换）时，无论是否 dirty 都保留缓冲并要求重新选择授权后读取。文件移除／不可读不自动重新创建；只读文件保留缓冲并允许另存。恢复原文件的权限必须来自经复验的宿主授权记录；失败仍保留草稿，只能另存或重新选择原文件。

#### Scenario: 外部覆盖或删除

- GIVEN 打开的文件有本地 dirty。
- WHEN 外部程序修改或删除该文件，应用刷新或保存。
- THEN 保留缓冲、报告冲突／缺失，不覆盖外部内容或自动重建，可另存副本。

#### Scenario: 未授权路径与身份变化

- GIVEN 伪造路径／授权 ID，或已授权路径被替换为另一目标。
- WHEN 前端请求读取、恢复或保存。
- THEN 后端拒绝，未授权文件不被读取或修改；合法草稿仍可另存，身份变化需重新选择授权。

### Requirement: TEXT-08 本机草稿与恢复

文本模块必须（MUST）在停止编辑 1 秒后尝试暂存未命名／未保存正文及格式、磁盘基准、标签和视图状态，并在正常切换模块、隐藏和退出前强制提交最新代。暂存只写本机应用数据，界面说明未写原文件；不将正文写入配置或日志，不持久化撤销栈。

恢复必须采用版本化原子清单，提交新清单前失败／配额不足保留上个有效代及当前缓冲。新清单成功提交即确认新代，随后旧数据清理失败仅报告警告并继续计入配额，不回滚新代。正常退出保留恢复记录，重启恢复；显式不保存关闭必须成功删除对应恢复引用后才关闭。恢复损坏保留并提示，不用空白覆盖；磁盘已变更时保留草稿并提示冲突，缺失时可另存。

#### Scenario: 未命名和 dirty 正常恢复

- GIVEN 未命名 A 和已命名但 dirty 的 B，最新恢复提交成功。
- WHEN 隐藏 60 秒后唤起，或正常退出并重启。
- THEN 标签顺序、正文、格式、活动视图和光标／滚动恢复；B 仍显示未保存到原文件，原文件未被暂存改写。

#### Scenario: 恢复失败与显式丢弃

- GIVEN 暂存写入失败、恢复清单损坏，或用户选择不保存关闭。
- WHEN 处理隐藏／恢复／关闭。
- THEN 写失败阻止会丢失内存的动作并允许重试；损坏记录保留并报告；明确关闭的草稿不在重启时复活，删除失败保留标签。

### Requirement: TEXT-09 有界正文与操作

单文件原始读取／保存不得（MUST NOT）超过 16 MiB，超过 2 MiB 打开前确认；全部文本标签当前正文合计不超过 16 Mi 个 UTF-16 代码单元，最多 12 标签。输入、粘贴、替换、转换及恢复均在提交前校验，不截断／部分接受。撤销历史沿用每文档 200 次正文变更或累计 4 Mi 插入代码单元的重置边界，当前正文不因历史淘汰丢失。

#### Scenario: 配额边界

- GIVEN 文本工作区接近单文件／总正文／标签上限。
- WHEN 打开、粘贴或全部替换将超出边界。
- THEN 此次操作被明确拒绝，已有正文、磁盘和标签不变；用户可关闭文档后重试。
