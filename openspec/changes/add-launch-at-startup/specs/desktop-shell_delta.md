# Delta: 桌面工作台自启动

**Change ID:** `add-launch-at-startup`
**Affects:** SHELL-01、SHELL-04；新增 SHELL-05、SHELL-06；沿用 PERF-01、PERF-02

## ADDED

### Requirement: SHELL-05 当前用户开机自启动

Windows 桌面发布版必须（MUST）在设置中提供「开机自启动」，表示当前副本的当前用户登录启动项是否已注册。没有已有注册项的新装或旧版升级默认关闭；仅用户变更开关并成功保存后启用或关闭。取消设置不得（MUST NOT）写入自启动项。

每次打开设置必须查询系统注册状态并展示目标位置，区分未注册、当前副本、另一副本及读取失败。读取失败显示未知及重试，不假定关闭或报告成功，其他可用设置仍可保存。另一副本占用时提示主动开启可切换到当前程序；关闭只删除匹配当前副本的项。外部删除后不得根据缓存补回，保存其他设置不得重写注册；检测到外部变更必须刷新状态并提示重试。

开关不代表 Windows 允许运行，必须说明系统禁用可能阻止启动，不覆盖系统禁用或策略。自动启动必须携带 `--autostart` 来源标记，在用户登录后仅初始化配置、托盘、全局快捷键及按偏好显示的悬浮入口；不得主动显示主窗口、抢占焦点、读取笔记正文或启用剪贴板监听。主 WebView 在用户唤起时才创建，恢复既有模块与最多两个文档会话。可恢复的配置解析错误及快捷键注册失败保留至首次打开界面提示，不自动弹窗抢焦点。

#### Scenario: 开启、关闭及取消
- GIVEN 当前副本未注册自启动，拾页正常运行。
- WHEN 用户勾选「开机自启动」并成功保存。
- THEN 注册包含带引号绝对程序路径及 `--autostart` 的命令，重新打开设置显示开启和目标位置，不要求管理员权限。
- AND 取消修改不改变注册；关闭并保存移除当前副本的项，其他程序的项不受影响。

#### Scenario: 登录后后台就绪与首次唤起
- GIVEN 自启动已开启且未被系统禁止，悬浮入口偏好已保存。
- WHEN 当前用户注销后重新登录，Windows 执行拾页启动项。
- THEN 只有一个拾页实例，托盘及有效快捷键就绪，悬浮按偏好显示，主 WebView 尚未创建，不抢占焦点。
- AND 用户唤起后创建界面并恢复模块、文档和可恢复视图；之后隐藏与闲置卸载遵守 SHELL-04 和 PERF-02。

#### Scenario: 外部删除或系统禁用
- GIVEN 拾页曾成功注册自启动。
- WHEN 注册值被删除后重新打开设置，或 Windows 设置／任务管理器禁止执行拾页。
- THEN 删除后显示关闭；系统禁用不被应用重新启用，注册存在不被描述为必然会运行，界面提供检查系统启动设置的说明。
- AND 手动启动、打开设置和保存其他设置不自动创建或重写自启动项。

#### Scenario: 注册指向另一副本
- GIVEN 固定拾页注册项指向另一个目录中的程序。
- WHEN 用户在当前副本中打开设置、保存其他设置或关闭当前副本的自启动。
- THEN 显示另一目标位置，不误删或重写该值；当前副本未注册时的关闭操作为无操作。
- AND 用户主动开启并成功保存时切换到当前绝对路径；保存前发现外部变更则刷新状态并提示重试。

#### Scenario: 操作失败与恢复
- GIVEN 用户修改快捷键、悬浮入口或自启动选项。
- WHEN 自启动写入／读回或本地设置保存失败。
- THEN 设置界面保留错误及重试入口，不提示成功，尝试恢复原始注册值、有效快捷键及本地设置。
- AND 恢复也失败时，明确说明部分变更及恢复失败，重新查询实际状态，不用旧勾选值掩盖结果。

#### Scenario: 读取失败或浏览器预览
- GIVEN 注册状态无法读取，或用户处于浏览器预览环境。
- WHEN 用户打开设置。
- THEN 读取失败显示未知、错误及重试；浏览器禁用开关并说明仅 Windows 桌面版可用；其他可用设置保持可操作，不虚构注册成功。

### Requirement: SHELL-06 自启动路径与安装生命周期

应用必须（MUST）使用当前用户下单个固定拾页注册值，正确引用当前程序绝对路径，支持中文／空格路径；命令超过 Run 的 260 字符限制或不可注册时显式失败并保留原值。开发构建与隔离数据目录运行不得修改正式值，验收使用独立应用身份及注册值名。

NSIS 正常卸载必须仅清理目标匹配被卸载程序的拾页值，不删除其他副本或其他程序的项，清理失败显式反馈。覆盖升级必须保留开启／关闭状态，必要时更新安装路径，不因升级卸载旧版本丢失开关。独立程序移动后不自动寻找新路径，提供在新位置主动开启并保存、替换旧路径注册的说明。

#### Scenario: 安装、升级与卸载
- GIVEN 用户未启用自启动，或已有启用／关闭状态的安装版。
- WHEN 首次安装、覆盖升级或正常卸载拾页。
- THEN 首次安装不注册，升级保留原开关和有效程序路径，正常卸载移除指向被卸载程序的项，清理失败反馈。
- AND 注册已指向另一位置时，卸载本副本不删除该值；其他启动项保持不变。

#### Scenario: 路径与隔离验收
- GIVEN 发布版位于中文／空格目录，或构造的启动命令超过 260 字符，或程序处于开发／隔离验收环境。
- WHEN 用户启用自启动或开展测试。
- THEN 有效路径正确注册，超长命令被拒绝且保留原值；独立程序移动后在新位置主动开启并保存更新路径；开发／隔离运行不写正式值，验收结束清理其独立项。

## MODIFIED

### Requirement: SHELL-01 全局快捷键与单实例

应用必须（MUST）支持可配置全局快捷键，默认 `Ctrl+Alt+Space`；隐藏或失焦时显示并聚焦已有主窗口，已聚焦时隐藏。重复手动启动必须激活已有实例；重复携带 `--autostart` 的后台启动复用已有实例且不改变窗口可见性、焦点或会话，不创建第二个主窗口。

#### Scenario: 其他应用在前台时唤起
- GIVEN 工作台已运行但隐藏或尚未创建主窗口，另一个应用拥有焦点。
- WHEN 用户按下已注册的快捷键。
- THEN 工作台显示并获得焦点，恢复上次模块与可恢复文档状态，不新建第二个主窗口。

#### Scenario: 快捷键冲突
- GIVEN 用户设置的组合键无法注册。
- WHEN 应用尝试注册该组合键。
- THEN 设置界面显示冲突或失败；原有效绑定可继续使用，悬浮与托盘仍可用。

#### Scenario: 手动启动与重复后台启动
- GIVEN 拾页尚未运行，或已有一个可见／隐藏实例。
- WHEN 用户手动运行程序，或 Windows／测试传入 `--autostart`。
- THEN 手动启动显示主窗口，已有实例时唤起该实例；自动启动无已有实例时后台就绪，有实例时保持其显示和焦点状态，第二进程退出。
- AND 重复启动不替换会话、不创建额外托盘或快捷键绑定。

### Requirement: SHELL-04 隐藏、卸载和退出

关闭主窗口必须（MUST）隐藏应用，保留系统入口。明确退出结束后台运行并释放入口与快捷键；退出仅结束本次运行，不清除自启动注册，不在当前登录会话自动重启。自启动尚未创建主界面时也可从托盘明确退出。隐藏、模块切换、退出及闲置卸载必须遵守保存协议；保存失败保留可见错误及编辑缓冲，允许重试、另存或取消操作。

#### Scenario: 隐藏后恢复
- GIVEN 笔记已保存，用户关闭主窗口。
- WHEN 应用隐藏并在闲置 60 秒后释放主界面，用户再次点击入口。
- THEN 从本地文件恢复上次文档及轻量视图状态，不丢失已保存内容；系统入口在隐藏期间持续有效。

#### Scenario: 保存失败或明确退出
- GIVEN 当前笔记有未保存修改。
- WHEN 用户尝试隐藏或退出而保存失败。
- THEN 操作暂停，编辑缓冲仍可访问；用户处理后明确退出，所有应用进程及系统入口结束。

#### Scenario: 无主界面的后台实例退出
- GIVEN 拾页自启动注册开启，主界面尚未创建或已安全卸载。
- WHEN 用户在托盘选择「退出拾页」。
- THEN 程序及系统入口结束，不为了退出创建主界面，不立刻重新启动，注册保留到下次登录。
