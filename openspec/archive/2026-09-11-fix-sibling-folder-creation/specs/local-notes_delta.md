# Delta: 本地笔记文件管理

**Change ID:** `fix-sibling-folder-creation`
**Affects:** FILE-02 文件树与新建

## MODIFIED

### Requirement: FILE-02 文件树与新建

笔记管理必须（MUST）左侧显示文件夹与笔记树、右侧显示正文；支持展开/折叠、新建文件夹、新建 `.md` 文件及手动刷新。点击笔记在活动窗格打开，若已打开则激活对应窗格。

#### Scenario: 在选定目录新建
- GIVEN 用户选中一个文件夹。
- WHEN 用户新建文件夹或输入不含扩展名的笔记名称。
- THEN 在该文件夹下创建真实目录或补 `.md` 的文件，成功后更新树；新笔记在活动窗格以编辑模式打开。

#### Scenario: 名称不合法或已存在
- GIVEN 同目录已有同名项目，或输入 Windows 非法文件名。
- WHEN 用户提交新建或重命名。
- THEN 不覆盖已有项目、不更新为虚假成功状态，并提示可修正的原因。

#### Scenario: 返回根目录或新建同级文件夹
- GIVEN 用户已选中或刚创建一个文件夹。
- WHEN 点击笔记库名称或文件树空白处后新建，或从文件夹右键菜单／更多文件操作中选择“新建同级文件夹”。
- THEN 返回根目录的新建操作在笔记库顶层创建项目；同级新建操作在所选文件夹的父目录创建文件夹，根目录和嵌套目录均适用。菜单明确区分“新建子文件夹”和“新建同级文件夹”，创建弹窗显示保存位置。
- AND 文件树空白处的右键菜单以根目录为目标，重命名和回收站操作不可用；返回根目录保留已打开笔记。
