# Delta: 代码着色资源

**Change ID:** `improve-editor-formatting`

## ADDED

### Requirement: PERF-05 有界预览着色
语言模块必须按需从本地构建产物加载并共用。预览先显示安全纯文本，进入视口的代码块才加载/解析。单块超过 100,000 UTF-16 字符时不着色、不截断，并说明以纯文本显示。不得建立跨文档正文或语法树缓存；关闭/替换窗格后清理观察器与待处理工作，过期结果不得写入新页面。

#### Scenario: 大代码块与快速切换
- GIVEN 超长代码块或尚未完成语言加载的预览。
- WHEN 查看代码或切换/关闭窗格。
- THEN 正文完整可读，不为超长块增加 token DOM；旧任务不能修改新窗格，语言加载失败不阻断阅读。
