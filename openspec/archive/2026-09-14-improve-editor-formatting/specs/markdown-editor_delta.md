# Delta: Markdown 编辑与显示

**Change ID:** `improve-editor-formatting`

## ADDED

### Requirement: EDIT-05 可见选区
编辑和显示模式必须清楚呈现选区。当前行背景不得遮住选区；编辑器失焦仍保留可辨认底色。

#### Scenario: 选择当前行及跨行文字
- GIVEN 一个或两个编辑窗格，包含自动换行的长行。
- WHEN 用鼠标或键盘选择文字，随后操作工具栏或聚焦另一窗格。
- THEN 所选范围可见，当前行不遮挡底色，各窗格选区独立。

### Requirement: EDIT-06 格式工具栏
每个编辑窗格必须提供正文/H1–H3、加粗、斜体、有序/无序/任务列表、引用、行内代码、代码块、链接、撤销/重做。按钮具有中文可访问名称，窄窗格可换行。行内格式使用选中文字或可替换占位文字；块格式处理当前/选中行，同格式可取消。每次修改为独立撤销事务，沿用自动保存。

#### Scenario: 不熟悉 Markdown 的用户排版
- GIVEN 从 TXT 粘贴的多行文字。
- WHEN 选中标题或条目并点击格式按钮。
- THEN 生成对应 Markdown，焦点返回编辑区，正文保留；一次撤销还原此次操作，切换模式显示最新内容。

#### Scenario: 代码块及链接弹窗
- GIVEN 选中一段代码或链接文字。
- WHEN 选择代码语言或输入链接并确认。
- THEN 自动生成有效 Markdown；内部反引号不提前关闭围栏；已有代码块仅更新语言。取消弹窗不改正文并恢复选区。

## MODIFIED

### Requirement: EDIT-03 Markdown 展示范围
继续支持原有 Markdown、图片与安全规则。显示模式额外保留段落内单次换行，不改写文件。编辑与显示模式对受支持、显式标明语言的代码块使用一致语法配色；未指定、未知或加载失败时保留完整纯文本。

#### Scenario: TXT 换行与代码着色
- GIVEN 含单次换行、空行和指定语言代码块的笔记。
- WHEN 编辑或显示笔记。
- THEN 显示模式保留单次换行及段落间隔，代码关键字/字符串等可区分，代码缩进与文本完整保留。
