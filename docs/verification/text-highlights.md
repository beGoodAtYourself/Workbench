# 文本选区背景标注（2026-10-29）

## 使用

在「文本编辑」中选中文字，点击工具栏「标注」旁的黄色、绿色、蓝色或粉色按钮即可填充背景。选中已有标注后点击「清除」可局部移除。支持多组选区、跨行范围及撤销／重做；没有选区时提示先选择文字。

文字编辑会调整标注范围：在标注之前插入文字会移动位置，在标注内部插入会继承颜色，边界外插入不会染色；完全删除的范围随文字消失，撤销删除会恢复标注。

标注单独保存在本机，不向 TXT、源码或配置文件插入 HTML，也不改变原文件的字节、编码、换行或文件身份。仅修改标注不触发原文件“未保存”状态；状态栏显示标注待暂存／已存本机，暂存失败可重试。Ctrl+S 和「全部保存」会立即提交尚未暂存的标注；重新载入前也会先提交标注。

已保存文件的标注可在关闭标签、重新打开和应用恢复后保留。未保存正文的标注跟随草稿；选择“不保存”丢弃修改时，保留原磁盘版本已有的标注。另存后，新路径保留当前标注。标注不随文件复制到其他电脑或其他编辑器，外部移动／改名也不会自动迁移本机路径索引。

## 持久化与限制

- CodeMirror 独立状态字段负责范围映射和撤销；装饰只在活动编辑器挂载，暂停与切换时保留纯状态。
- 恢复清单增加可选 `highlights` 字段，旧清单缺少该字段时仍可恢复。标注变化不重复发送已确认的正文。
- 已保存文件按规范路径摘要索引；存储 UTF-16 范围、四种受限颜色、正文摘要及长度。重新打开时只有标准化正文完全一致才附加标注，外部改动后不猜测重点位置。
- 索引位于应用数据目录 `text-recovery/annotations.json`，使用原子替换与校验。草稿先提交，索引写入失败不确认暂存成功；关闭标签前补交尚未保存的标注。
- 单文档最多 256 个标注段，全部活动文档最多 1024 段；本机索引最多 2048 个文件、4 MiB，并计入原有 128 MiB 恢复目录限额。超限或损坏时保留数据并报错，不静默淘汰其他文件的标注。
