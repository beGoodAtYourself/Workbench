# Markdown 导入（2026-11-17）

笔记管理左侧增加「导入 Markdown」文字按钮，更多文件操作及右键菜单提供同名入口。桌面版使用单文件原生选择框，只接受 `.md` 文件。

## 行为

- 目标目录沿用新建笔记规则：选中文件夹时导入其中，选中笔记时放在同级，未选中项目时放在笔记库根目录。未选择笔记库时先选择目录。
- 导入复制磁盘中的文件，保留源文件，以及 UTF-8 BOM、换行和正文原始字节。仅复制所选 Markdown，关联图片等附件需要另行放到笔记库中。
- 同名文件、大小写不同的同名文件以及同名文件夹都保留，导入副本自动命名为 `名称 (1).md`、`名称 (2).md` 等。即使并发导入，也通过禁止覆盖的文件提交保证已有项目不被替换。
- 先验证扩展名、UTF-8 和 64 MiB 上限，再写同目录临时文件，完整写入后提交。失败时清理临时文件；不生成半份笔记。
- 导入前保存当前笔记，文件选择期间保护界面及会话；取消选择不新增文件。文件选择框打开期间不持有后端文件锁，提交前再次确认笔记库与目标目录。
- 成功后展开目标目录、刷新并滚动定位新笔记，在活动窗格以显示模式打开。超过 2 MiB 的笔记沿用现有加载确认；取消加载或打开失败时明确提示文件已导入，保留列表中的副本。
- 浏览器预览使用文件选择框复制到独立示例存储，不写本机笔记库。
