# 拾页使用手册与版本记录

拾页是一个 Windows 本地 Markdown 工作台。通过悬浮入口或全局快捷键打开，在两个窗格中编辑、阅读和连接笔记，也可以查看当前剪贴板文本。笔记是你选择的文件夹里的普通文件，不需要账户、数据库或云服务。

## 独立文本编辑模块（2026-10-16）

顶部新增「文本编辑」，与「笔记管理」「剪贴板」并列。无需选择笔记库，就能新建文本，或通过原生对话框打开 `.txt`、日志、源码、配置文件及 Markdown；未知扩展名按纯文本处理。最多保留 12 个标签，可拖动排序或用「更多」菜单调整顺序；「双视图」并排显示两个不同文档，切换时保留各自光标、选区、滚动和可用撤销历史。

文本模块由「保存」「另存为」「全部保存」或 `Ctrl+S` 写回原文件。停止编辑约 1 秒后会自动尝试暂存本机草稿，未命名文本也会暂存；「已暂存本机」仍表示没有保存到原文件。切换模块、隐藏及正常退出前会提交最新草稿，下次打开恢复标签和未保存内容。笔记模块继续采用原来的 500 ms 自动保存。关闭未保存标签时可选择「保存／不保存／取消」；「不保存」会删除该标签的本机恢复引用。暂存失败会显示可重试错误，不能依赖强制结束进程或断电保留最近尚未提交的输入。

支持 47 个编码选项：UTF-8、UTF-16／UTF-32 LE／BE（分别保留有无 BOM）、GBK／GB2312／CP936、GB18030、Big5、Shift_JIS、EUC-JP、ISO-2022-JP、EUC-KR、Windows-1250～1258、Windows-874、ISO-8859 系列、KOI8、IBM866、Macintosh 及 ASCII。普通打开优先识别 BOM、无 BOM Unicode 特征和严格 UTF-8，再检测旧式编码；短文本或混合语言可能误判，可在「更多 → 指定编码打开」选择编码，已打开的乱码文件使用「更多 → 以其他编码重新打开」。手动读取编码会随原文件授权持久保存；状态栏编码用于保存转换，无法完整表示正文时拒绝写入并保留原文件。非法字节、空字符及明显二进制内容会被拒绝。新建默认 UTF-8 无 BOM／CRLF，现有文件保留编码和一致的 LF／CRLF。状态栏可以选择输出编码与换行，转换参与撤销；混合换行或 CR 文件编辑后，保存前必须明确选择统一为 LF 或 CRLF，取消会保留缓冲且不写文件。

工具栏新增「标注」：选中文字后可填充黄／绿／蓝／粉背景，或清除选区内标注，支持撤销重做与编辑位置跟随。标注在本机单独暂存，不修改原文件内容；已保存文件关闭重开后保留，未保存内容随草稿恢复。外部正文变化后不套用旧位置。标注不随文件复制到其他电脑；详细行为和限制见[标注验证记录](verification/text-highlights.md)。

状态栏提供语言、行列、缩进宽度与自动换行设置。复用原有 18 种代码语言，并增加 Markdown、XML 与纯文本；按扩展名选择，也可手动切换。支持行号、括号匹配、可用语言的注释与折叠、Tab／空格和 2／4／8 宽度、`Alt+单击` 多光标，以及按 Unicode 码点计数的行列跳转。查找替换针对当前文档或捕获的主选区，支持大小写、Unicode 整词和 JavaScript Unicode／多行正则；正则替换支持 `$1`、`$<name>`、`$$`。查找最多 10,000 个匹配、单任务 1,500 ms；失败或超限不执行部分全部替换，成功的全部替换可一次撤销。

| 文本编辑快捷键 | 操作 |
| --- | --- |
| `Ctrl+N`／`Ctrl+O` | 新建／打开文本文件 |
| `Ctrl+S`／`Ctrl+Shift+S` | 保存／另存为 |
| `Ctrl+W` | 关闭当前文本标签 |
| `Ctrl+Tab`／`Ctrl+Shift+Tab` | 切换到下一个／上一个标签 |
| `Ctrl+F`／`Ctrl+H` | 查找／替换 |
| `F3`／`Shift+F3` | 下一个／上一个匹配 |
| `Ctrl+G` | 跳转行列 |
| `Ctrl+Z`／`Ctrl+Y` | 撤销／重做 |
| `Tab`／`Shift+Tab` | 缩进／反缩进 |
| `Ctrl+D`／`Ctrl+/` | 复制当前行／切换代码注释 |

文本单文件读取和保存产物上限为 16 MiB，打开超过 2 MiB 的文件先确认；全部文本标签正文合计最多 16 Mi 个 UTF-16 代码单元。达到标签或正文上限会拒绝本次操作，不裁剪内容或关闭其他标签。每份文档沿用 200 次正文变更或累计 4 Mi 个插入代码单元的撤销历史边界。恢复目录总配额为 128 MiB，包括临时文件与待清理旧代；单代正文最多 64 MiB、会话元数据最多 128 KiB，配额不足时保留最后有效草稿及当前缓冲。

同一文件已在笔记或文本模块打开时，再次打开会激活已有所属模块及会话，采用其原有保存方式。笔记树对已在文本模块打开的文件或其祖先执行改名、移动、回收站操作时，会要求先关闭相关文本标签；纯排序仍可用，切换笔记库也保留独立文本标签。外部文件变化、只读、删除或身份改变时会保留本地缓冲并提示处理，可另存副本；明确确认重新载入会丢弃当前本地修改。

本次不包含跨标签／目录搜索、矩形列编辑、宏、插件兼容、语言服务器、调试或执行代码、FTP／云同步、文件对比、打印、系统文件关联、同文档克隆、多窗口及超大日志流式查看。浏览器预览只操作独立示例存储，原生文件对话框、字节保存和桌面生命周期以 Windows 发布版验收为准。

1. 打开拾页，点击“选择笔记文件夹”，选择一个已有目录或新建的空目录。
2. 左侧展示文件夹和 `.md` 文件。选中文件夹后，新建操作会在其中创建项目；选中文件时，会在同级目录创建。要建立并列文件夹，可右键文件夹或点击“更多文件操作”，选择“新建同级文件夹”。点击左上方笔记库名称或文件树空白处可返回根目录，再新建顶层文件夹；更换笔记库仍使用“选择笔记文件夹”按钮。
3. 点击「导入 Markdown」可添加已有 `.md` 文件；选中文件夹时导入其中，选中笔记时导入同级，点击笔记库名称后导入根目录。导入采用复制，源文件保持不变，同名自动使用 `名称 (1).md` 等名称，成功后自动显示并打开。更多文件操作和右键菜单也提供此入口。
4. 点击笔记，在当前活动窗格打开。已有笔记和导入笔记默认显示，新建笔记默认编辑。
5. 每个窗格右上角可以独立切换“显示”和“编辑”。停止输入 500 ms 后自动保存，也可以按 `Ctrl+S`。

左侧“更多文件操作”、右键菜单、`F2` 和 `Delete` 提供重命名及移至回收站操作。删除需要确认，失败不会改为永久删除。**重命名不会自动修改其他笔记中的链接**，需要自行修复引用。

## 整理文件夹与笔记

拖动一个文件夹即可调整顺序或移动位置：行上沿／下沿出现插入线时，放在该文件夹之前／之后；行中部出现绿色边框时，移入该文件夹。拖到左上方笔记库名称可移回根目录。不同父目录之间的移动会先显示源路径和目标路径，确认后才移动；按 `Esc` 或取消可放弃。

单篇 `.md` 笔记也能整理：拖到另一篇笔记行的上半／下半，出现插入线后放开，即放在该笔记之前／之后；拖到文件夹行任意位置则移入该文件夹，拖到笔记库名称可移回根目录。跨父目录时先确认移动；拖到编辑正文仍是插入链接。

右键文件夹或笔记，或点击“更多文件操作”，也可使用“上移”“下移”“移动到…”和“恢复同级默认排序”。文件树获得焦点后，可用上下方向键选择，再按 `Shift+F10` 打开菜单。“移动到…”按层级浏览目标，支持返回上级和选择根目录。长列表拖动到上下边缘会自动滚动。

自定义顺序按笔记库分别保存在应用本地偏好中，刷新、折叠展开、隐藏及重启后仍保持。文件夹继续在笔记前面，两组各自排序；新增文件夹或笔记追加到所属组已排定的项目后。应用内改名在有自定义顺序时保留位置；外部改名按新增处理。恢复默认排序同时还原当前层两组的名称顺序，不清除子目录设置。已有文件夹顺序兼容保留。排序记录每库上限为 1 MiB，超限或写入失败会提示，不截断记录。

跨目录移动文件夹会保留其中的图片和其他文件；移动单篇笔记只移动该 `.md` 文件，附件仍在原处。打开的笔记先完成保存，再同步到新路径，编辑模式和正文撤销历史保留；同名、移入自身／后代及库外位置会被拒绝。

**移动不会自动改写 Markdown 链接或图片引用。** 例如在根目录的笔记中，原链接 `[资料](项目/资料/A.md)` 在目录移到 `归档` 后需改为 `[资料](归档/资料/A.md)`；目录内相对位置未变的引用通常仍有效。移动确认会说明这一影响。

若提示“磁盘操作已完成，但文件夹顺序未保存”或“恢复记录未保存”，文件已经在新位置。处理权限等问题后，点击文件树下方的“重试保存”即可重试记录保存，不要重复移动。顺序记录损坏时保留原记录并提示；笔记文件不会为恢复排序而被重写。

## 不用记 Markdown 语法也能排版

编辑模式的格式工具栏提供正文、一级至三级标题、加粗、斜体、列表、任务、引用、行内代码、代码块、链接和撤销／重做。选中文字后点按钮即可生成 Markdown；标题、列表和引用处理当前行或选中行，再次应用相同格式会取消。没有选中文字时，行内格式插入可直接替换的占位文字。每次格式操作可以一步撤销，并照常自动保存；加粗和斜体也可用 `Ctrl+B`、`Ctrl+I`。

从 TXT 复制文字后直接粘贴即可。显示模式现在保留段落内的单次换行，空行仍用于分段；这也会改变已有笔记里手动折行段落的显示，但不会因此改写文件。需要标题或列表时用工具栏设置，应用不会自动猜测文字结构。

选中代码后点击“代码块”，选择语言并应用。支持 JavaScript、TypeScript、JSX、TSX、Python、Java、C、C++、C#、Go、Rust、HTML、CSS、JSON、SQL、Shell、PowerShell 和 YAML，以及 `js`、`ts`、`py`、`bash`、`ps1` 等常见标记。编辑和显示使用同一套语法配色；光标在已有代码块中时，该按钮改为修改语言，其他文字格式按钮暂不可用。

代码块默认“纯文本”；未标明、不支持或加载失败的语言保持完整纯文本。预览中的单块代码超过 100,000 个 UTF-16 字符时显示“大代码块 · 按纯文本显示”，不会截断内容。语言模块随安装包提供，使用时无需联网。

## 随时调出

- 默认全局快捷键：`Ctrl+Alt+Space`。主窗口已聚焦时隐藏，隐藏或失焦时显示并聚焦。
- 点击桌面上的“拾”悬浮入口打开；拖动改变位置。设置中可以关闭入口或更换快捷键。
- 快捷键注册失败时，会提示原因并保留原绑定。
- 托盘菜单可以显示主窗口、切换悬浮入口或退出。
- 关闭主窗口会隐藏到后台。隐藏 60 秒后释放主界面，再次唤起时从磁盘恢复最近的模块、笔记、模式和滚动位置。
- 完全结束运行，请使用“设置 → 退出拾页”或托盘“退出拾页”。

## 连接笔记与双分屏

把左侧的笔记拖进编辑区，在鼠标落点生成 Markdown 相对链接，例如：

```md
[项目计划](../项目/计划.md)
```

生成的路径会编码中文和特殊字符，仍然是可由其他 Markdown 工具读取的标准链接。文件夹和显示模式不能插入链接。

- 显示模式单击链接打开；编辑模式使用 `Ctrl+单击`，普通单击只定位光标。
- 从 A 打开 B，显示 `A | B`。
- 在右侧 B 继续打开 C，显示 `B | C`。
- 最多两个笔记窗格；目标已打开时复用会话，自身链接不会新增窗格。
- 关闭右窗格回到单栏。发生保存问题时保留原布局和修改。
- 支持标题片段，如 `[下一节](指南.md#下一节)`。HTTP/HTTPS 链接在系统浏览器中打开。

## 保存与外部修改

页脚显示“未保存”“正在保存”“已保存到本地”或保存错误。应用使用版本校验、串行写入和同目录临时文件替换，保留已有 UTF-8 BOM 和 CRLF 换行风格。

其他编辑器改动了已打开的文件时，返回拾页或点击刷新会检查变化。没有未保存修改时读取新版本；存在本地修改时提示冲突，保留双方内容。点击错误旁的“处理”可重试、另存本地副本，或确认丢弃本地修改并重新载入磁盘内容。

保存失败会阻止隐藏、退出、切换工作区和会移出未保存笔记的跳转。此时不要直接结束进程，应先保存副本或处理错误。自动保存不是备份；突然断电或强制结束可能失去最后尚未写入的输入。

笔记必须是 UTF-8；不支持的编码会明确报错。首版不进入笔记库内部的符号链接或 Windows junction，不打开库外笔记。

## 剪贴板

顶部“剪贴板”显示系统当前文本，可手动刷新，可见期间自动更新。支持空内容、非文本、繁忙和读取失败状态。首版不收集历史，不写入磁盘或日志，也不修改剪贴板。

最多读取并保留前 1 MiB UTF-8 文本，截断保持完整字符并显示说明。长文本分段浏览，避免一次排版大量文字或表情。离开模块或隐藏后释放快照，返回时重新读取当前内容。

## 资源与大文件

- 正文按打开动作读取；笔记最多两个会话，文本最多 12 个文档，主窗口同时最多挂载两个编辑器。目录按需加载，文件列表按可见范围渲染，最多展开 300 个目录。
- 超过 2 MiB 的笔记先提示，可继续或取消；超过 64 MiB 明确拒绝，不截断后覆盖原文件。
- 编辑器按视口创建行；撤销缓冲达到 200 次文档变更或累计 4 Mi 个插入字符时重置，保留当前正文及光标。模式切换保留上限内的撤销状态。
- 本地 PNG/JPEG/GIF/WebP 图片上限 4 MiB、800 万像素，每个显示窗格同时保留最多两张图片，超限时显示占位。
- 原始 HTML 作为文本展示，远程图片不会自动请求。任务列表在显示模式中只读。

## 开机自启动

打开新版「设置」，勾选「开机自启动」并保存。默认关闭，仅对当前 Windows 用户生效；登录后在后台运行，按保存的偏好显示悬浮入口，通过托盘或全局快捷键调出主界面。

取消设置不改变注册，关闭开关并保存停止后续登录启动。「退出拾页」只结束本次运行，保留自启动选择，当前会话不会自动重启。开关表示该程序的启动项已注册；若系统禁止执行，可在 Windows「设置 → 应用 → 启动」中检查。

设置会显示注册目标位置。独立程序移动后，在新位置主动开启并保存即可替换旧路径；注册已指向另一副本时，关闭／卸载当前副本不会删除另一副本的项。浏览器预览和开发构建提供不可用说明，其他设置仍可保存。

真实登录及完整系统入口验收仍见[本次验证记录](../openspec/changes/add-launch-at-startup/verification.md)。

## 开发与构建

需要 Node.js、Rust MSVC 工具链、Visual Studio C++ Build Tools、Windows SDK 和 WebView2。依赖版本由 `package-lock.json` 与 `src-tauri/Cargo.lock` 锁定。

```powershell
git clone https://github.com/beGoodAtYourself/Workbench.git
cd Workbench
npm ci
npm run desktop
```

`npm run desktop` 运行完整桌面程序。`npm run dev` 是浏览器演示，使用浏览器本地示例数据，不操作真实笔记文件或系统入口。

```powershell
npm run check
npm test
npm run test:e2e
cargo test --manifest-path src-tauri/Cargo.toml
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
npm run package
```

安装包生成在 `src-tauri/target/release/bundle/nsis/`，源码中的 `npm run build` 仅构建界面。

配置位于 Tauri 当前用户配置目录下的 `local.shiye.workbench/settings.json`，只保存目录、快捷键、窗口位置和恢复元数据。测试脚本通过 `SHIYE_DATA_DIR` 使用独立目录。`SHIYE_PROFILE=1` 仅用于验收：记录唤起时间并允许对已隐藏窗口提前触发卸载；日常运行不需要这些变量。

自启动注册状态来自 Windows 当前用户 Run 值，不写入本地布尔缓存。正式值禁止开发及隔离数据目录运行修改；自启动原生验收仅使用 `scripts/startup-native-config.json` 的独立身份和进程名，并配合 `SHIYE_AUTOSTART_QA=1` 使用固定 QA 值。验收脚本会清理自身注册项，不能用正式身份代替 QA 构建。

NSIS 自启动生命周期使用 `src-tauri/windows/installer.nsi` 与 hooks。模板锁定 Tauri CLI 2.11.4／bundler 2.9.4，上游原文与 MIT 许可证保留；更新 CLI 时先复核模板差异并执行 `node scripts/check-startup-installer.mjs`，再验收安装与卸载。
